# Klasifikasi DemogPairs Menggunakan ViT (Emosi dan Wajah) & SVM

**Notebook:** `2.1.6_svm_vit-emotion-face_demogpairs.ipynb`

---

## 1. Deskripsi

Notebook ini melakukan klasifikasi data DemogPairs menggunakan fitur gabungan dari dua model ViT — ViT-Emotion dan ViT-Face — dengan classifier SVM (Support Vector Classifier). Pipeline mencakup opsi scaling (MinMaxScaler) dan reduksi dimensi (PCA), dengan pencarian hyperparameter menggunakan GridSearchCV.

---

## 2. Dataset

**Total sampel:** 10,800 gambar  
**Jumlah kelas:** 6 (demografi berdasarkan ras dan gender)  
**Database:** CWF (CelebFaces-in-the-Wild)

| Kelas | Contoh Label |
|---|---|
| Asian_Females | `label_idx = 5` |
| Asian_Males | — |
| Black_Females | — |
| Black_Males | `label_idx = 3` |
| White_Females | — |
| White_Males | `label_idx = 3` |

**Split data:**
- **Train:** 8,640 sampel (80%)
- **Test:** 2,160 sampel (20%)
- Stratified split, `random_state=42`

---

## 3. Fitur

- **Sumber fitur:** Gabungan ViT-Emotion + ViT-Face
  - `features/demogpairs_vit-emotion.pkl`
  - `features/demogpairs_vit-face.pkl`
- **Dimensi fitur per gambar:** 1,536
- **Proses penggabungan:** Fitur emosi dan wajah dikonkat menjadi vektor tunggal per gambar

---

## 4. Konfigurasi Eksperimen

### Pipeline
```
Pipeline: [Scaler (opsional)] → [PCA (opsional)] → [SVM Classifier]
```

### Parameter Grid (SVC)
| Parameter | Nilai yang Diuji |
|---|---|
| `scaler` | `None`, `MinMaxScaler()` |
| `pca` | `None`, `PCA(0.5)`, `PCA(0.75)` |
| `classifier__C` | 0.01, 0.1, 1, 10 |
| `classifier__kernel` | `rbf`, `poly`, `linear` |
| `classifier__gamma` | `scale`, `auto` |
| `classifier__degree` | 2, 3 |
| `classifier__tol` | 0.001 |
| `classifier__probability` | True |

**Total kombinasi parameter:** 288

### Cross-Validation
- **Metode:** StratifiedKFold
- **Jumlah fold:** 5
- **Scoring:** Accuracy, F1 (macro), Precision (macro), Recall (macro)
- **Refit berdasarkan:** Accuracy
