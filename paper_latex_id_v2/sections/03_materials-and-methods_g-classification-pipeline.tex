\subsection{Classification Pipeline}
\label{sec:classification_pipeline}

Pipeline modular mengintegrasikan penskalaan fitur (None, MinMaxScaler), reduksi dimensi PCA (None, 50\%, 75\%), dan pengklasifikasi hilir ke dalam rantai pemrosesan terpadu. Rantai transformasi dimodelkan pada \eqref{eq:12}, di mana vektor masukan $\mathbf{x}$ diskalakan menjadi $\tilde{\mathbf{x}}$, direduksi via proyeksi PCA menjadi $\hat{\mathbf{x}}$, lalu dipetakan ke estimasi label $\hat{y} \in \{0, \dots, K-1\}$ untuk $K = 6$ subkelompok interseksional. Untuk menjamin zero identity leakage dan zero statistical leakage, penskalaan dan PCA di-fit ketat hanya pada lipatan latih 5-Fold StratifiedGroupKFold GridSearchCV pada subset latih (480 subjek, 8.640 citra) dengan isolasi groups = subject\_id. Penelusuran hyperparameter merekonsiliasi (SVM: 288 + LR: 96 + RF: 288 + GNB: 240) = 912 kombinasi hyperparameter per skema fitur $\times$ 5 folds = 4.560 fits per skema fitur $\times$ 7 skema fitur = 31.920 fits validasi silang + 28 refits akhir pada subset latih sebelum evaluasi held-out.

\begin{equation}
\mathbf{x} \xrightarrow{\text{Scaler}} \tilde{\mathbf{x}} \xrightarrow{\text{PCA}} \hat{\mathbf{x}} \xrightarrow{\text{Classifier}} \hat{y} \in \{0, \dots, K-1\}
\label{eq:12}
\end{equation}
