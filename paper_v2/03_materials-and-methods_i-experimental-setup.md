## I. Experimental Setup

Seluruh eksperimen komputasi pada penelitian ini dijalankan pada infrastruktur perangkat keras yang mencakup prosesor Intel Core i9-13900H (14 core, 20 thread), memori utama Random Access Memory (RAM) 32GB DDR5 berkecepatan tinggi, serta NVIDIA GeForce RTX 4060 Laptop Graphics Processing Unit (GPU) dengan 8GB Video Random Access Memory (VRAM). Alokasi beban komputasi menerapkan skema hibrida terkoordinasi demi efisiensi eksekusi pemrosesan data. Tahapan ekstraksi representasi laten Vision Transformer memanfaatkan akselerasi GPU NVIDIA melalui PyTorch, sedangkan pelatihan model dan penalaan hyperparameter 5-fold cross-validation untuk pengklasifikasi klasik dioptimalkan pada multicore Central Processing Unit (CPU) berbasis scikit-learn. Tumpukan perangkat lunak dibangun di atas Python 3.10 dengan pustaka PyTorch (`torch`) dan scikit-learn (`sklearn`) dalam lingkungan terisolasi untuk menjamin reproduktibilitas penuh seluruh prosedur eksperimen.
