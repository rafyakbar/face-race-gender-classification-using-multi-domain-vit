----------------------------------------------------------------------------------------------------

- README.AI.md
  Panduan dan konteks komprehensif untuk agen kecerdasan buatan (AI) / pengembang terkait alur kerja,
  tata kelola repositori, dan instruksi khusus riset.
- WORKFLOW.md
  Alur kerja sistematis riset, mulai dari persiapan dataset, ekstraksi fitur laten, eksperimen
  klasifikasi hilir, hingga penyusunan naskah publikasi.
- paper_outline.md
  Kontrak master naskah publikasi (paper blueprint) yang menetapkan struktur bab per bab, target
  jumlah kata per paragraf, rancangan tabel/figur, dan metrik eksperimen.
- prompts.txt
  Catatan riwayat seluruh prompt dan arahan instruksi pengguna yang dieksekusi secara kronologis.
- scopus_query.txt
  Kumpulan kueri penelusuran basis data Scopus yang digunakan untuk mengumpulkan literatur relevan.
- folder_structure.txt
  Berkas ini, berisi visualisasi diagram pohon direktori dan penjelasan fungsional setiap komponen repositori.
- .gitignore
  Daftar berkas dan folder yang diabaikan oleh Git, termasuk dataset gambar mentah, checkpoint, dan cache.


2. DIREKTORI EXPERIMENT/ (EKSPERIMEN & KODE SUMBER)
----------------------------------------------------------------------------------------------------
Direktori ini mendokumentasikan seluruh tahapan eksperimen empiris, implementasi kode, dan artefak hasil:
- 00_overview.md
  Ringkasan metodologi eksperimen, kerangka kerja ekstraksi, dan protokol evaluasi.
- 01_prepare-data.md
  Dokumentasi pemrosesan dataset DemogPairs dan struktur metadata subkelompok.
- 02_preprocessing.md
  Spesifikasi standardisasi citra (konversi 3-channel RGB, resize 224 x 224, dan penskalaan intensitas [0, 1]).
- 03_feature-extraction.md
  Detail teknis ekstraksi fitur laten offline dari token [CLS] berdimensi 768 dari tiga model ViT-Base.
- 04_methods.md
  Deskripsi empat famili pengklasifikasi (SVM, GNB, RF, LR) dan optimasi GridSearchCV 5-Fold Stratified CV.
- 05_results.md
  Rekapitulasi lengkap metrik akurasi, presisi, recall, dan skor F1 di seluruh konfigurasi eksperimen.
- dataset_demogpairs.md
  Spesifikasi detail dataset DemogPairs (10.800 citra, 600 subjek, 6 kelas interseksional seimbang).

Sub-direktori experiment/code/:
- 1.1_vit-face_demogpairs.ipynb
  Notebook ekstraksi fitur biometrik wajah menggunakan model ViT-Base pre-trained (skutaada/VIT-VGGFace).
- 1.1_vit-emotion_demogpairs.ipynb
  Notebook ekstraksi fitur ekspresi afektif menggunakan model ViT-Base (dima806/facial_emotions_image_detection).
- 1.1_vit-age_demogpairs.ipynb
  Notebook ekstraksi fitur estimasi usia biologis menggunakan model ViT-Base (dima806/facial_age_image_detection).
- 2.1.1 s.d. 2.1.7_svm_*_demogpairs.ipynb
  Tujuh notebook eksperimen pengklasifikasi Support Vector Machine (SVM) untuk 7 variasi ablasi fitur.
- 2.2.1 s.d. 2.2.7_gnb_*_demogpairs.ipynb
  Tujuh notebook eksperimen pengklasifikasi Gaussian Naive Bayes (GNB) untuk 7 variasi ablasi fitur.
- 2.4.1 s.d. 2.4.7_rf_*_demogpairs.ipynb
  Tujuh notebook eksperimen pengklasifikasi Random Forest (RF) untuk 7 variasi ablasi fitur.
- 2.5.1 s.d. 2.5.7_lr_*_demogpairs.ipynb
  Tujuh notebook eksperimen pengklasifikasi Logistic Regression (LR) untuk 7 variasi ablasi fitur.
- 3.0_compare.ipynb
  Notebook analisis komparatif dan agregasi kinerja dari seluruh 28 konfigurasi eksperimen.
- 4.0_test.ipynb
  Notebook evaluasi akhir pada held-out test set dan analisis pola kesalahan (confusion matrix).
- app.py
  Skrip aplikasi inferensi demonstrasi berbasis Python.
- dataset/demogpairs/metadata/
  Folder berkas metadata teks (.txt) berisi daftar citra per kelas interseksional.
- images/
