# Klasifikasi DemogPairs Menggunakan ViT (Wajah) & SVM (Subject-Disjoint Evaluation)

> **Catatan Metodologi & Revisi Komentar Reviewer 2 (No. 2 & No. 8):**
> Notebook ini memperbarui protokol eksperimen dengan menerapkan **Strictly Subject-Disjoint Stratified Split**:
> 1. **Pembagian Data Subjek:** 100 subjek unik per kelas dibagi secara terstratifikasi 80:20 (80 subjek latih dan 20 subjek uji per kelas), menghasilkan tepat 8.640 sampel latih dan 2.160 sampel uji held-out dengan **0% tumpang tindih identitas (identity overlap)**.
> 2. **Cross-Validation Bebas Kebocoran:** Menerapkan `StratifiedGroupKFold(n_splits=5, shuffle=True, random_state=42)` pada data latih dengan pengelompokan `groups=groups_train` sehingga setiap fold CV juga sepenuhnya *subject-disjoint* (16 subjek per kelas per fold).
> 3. **Profil Efisiensi Komputasi (Reviewer 1 #5 & Reviewer 2 #8):** Melaporkan metrik komputasi lengkap mencakup durasi pelatihan, latensi inferensi per sampel (ms), dan ukuran penyimpanan model.

## Split Data (Strictly Subject-Disjoint & Class-Stratified)

Menggunakan fungsi `u.split_demogpairs_subject_disjoint` untuk membagi 600 subjek (100 per kelas) secara terstratifikasi 80:20 dengan seed 42. Setiap subjek (18 citra) hanya berada pada satu partisi (train atau test), menjamin 0% identity leakage.


```python
train_idx, test_idx = u.split_demogpairs_subject_disjoint(data, train_ratio=0.8, random_state=42)

X = np.array([features[d['image_path']] for d in data])
y = np.array([d['label_idx'] for d in data])
groups = np.array([d['subject_id'] for d in data])

X_train, X_test = X[train_idx], X[test_idx]
y_train, y_test = y[train_idx], y[test_idx]
groups_train, groups_test = groups[train_idx], groups[test_idx]

train_subs = set(groups_train)
test_subs = set(groups_test)
overlap = len(train_subs.intersection(test_subs))

print("=== VERIFIKASI PARTISI SUBJECT-DISJOINT ===")
print(f"Train samples: {len(X_train)} ({len(train_subs)} subjek unik)")
print(f"Test samples : {len(X_test)} ({len(test_subs)} subjek unik)")
```

## Kombinasi Parameter (GridSearchCV with StratifiedGroupKFold)

Menyiapkan ruang pencarian hyperparameter untuk SVM (288 kombinasi) sesuai Tabel VI naskah, dengan `StratifiedGroupKFold` 5-Fold untuk menjamin setiap lipatan validasi silang bebas kebocoran identitas subjek (16 subjek per kelas per fold).


```python
grid_params = [
    {
        'scaler': [None, MinMaxScaler()],  # EN: scaling option / ID: opsi scaling (2)
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],  # EN: with and without PCA / ID: dengan dan tanpa PCA (3)
        
        'classifier': [SVC()],  # EN: SVM model / ID: model SVM
        
        'classifier__C': [0.01, 0.1, 1, 10],  # EN: regularization / ID: regularisasi (4)
        'classifier__kernel': ['rbf', 'poly', 'linear'],  # EN: kernel types / ID: jenis kernel (3)
        
        'classifier__gamma': ['scale', 'auto'],  # EN: gamma / ID: gamma (2)
        'classifier__degree': [2, 3],  # EN: degree / ID: derajat (2)
        
        'classifier__tol': [1e-3],  # EN: tolerance / ID: toleransi
        'classifier__probability': [True],  # EN: probability / ID: probabilitas
    },
]

pipeline = Pipeline(steps=[
    ('scaler', None),  # EN: optional scaler / ID: scaler opsional
    ('pca', None),     # EN: optional PCA / ID: PCA opsional
    ('classifier', None)  # EN: classifier / ID: classifier
])

# Menggunakan StratifiedGroupKFold agar fold CV bersifat subject-disjoint
skv = StratifiedGroupKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy', 
    'f1': 'f1_macro', 
    'precision': 'precision_macro', 
    'recall': 'recall_macro'
}

grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.6),
        verbose=1, error_score='raise',
        return_train_score=True
    )
    print(f'{key}: {len(ParameterGrid(params))} kombinasi (5-Fold CV = {len(ParameterGrid(params)) * 5} fits)')
```

## Rangkuman Performa Tiap Fold Cross-Validation


```python
def remove_keys(data, keys_to_remove, inplace=False):
    if not inplace:
        data = data.copy()
    for key in keys_to_remove:
        data.pop(key, None)
    return data

def dict_to_sentence(d):
    parts = [f"{k}={v}" for k, v in d.items()]
    return ", ".join(parts)
```
