# Laporan Eksperimen 2.5.2 — Klasifikasi DemogPairs Menggunakan ViT (Emosi) & Logistic Regression

> **Sumber notebook:** `D:/Research/face-race-gender-multi-vit/experiment/code/2.5.2_lr_vit-emotion_demogpairs.ipynb` (JSON, 16 cells). Laporan ini disusun **self-contained** dengan hanya mengutip isi sel dan output yang benar-benar ada di notebook — tanpa mengarang data. Jika suatu sel tidak memiliki output, ditulis eksplisit.

Notebook berjudul *Klasifikasi DemogPairs Menggunakan ViT (Emosi) & Logistic Regression* mengevaluasi pipeline **Vision Transformer pra-latih emosi → Logistic Regression** pada dataset **DemogPairs** (6 kelas ras-gender). Fitur ViT-Emotion 768-dim diekstrak offline (`features/demogpairs_vit-emotion.pkl`), dibagi stratifikasi 80/20, kemudian di-tuning dengan `GridSearchCV` (StratifiedKFold 5-fold) atas kombinasi scaler/PCA/hyperparameter LR. Model terbaik di-refit pada data latih penuh dan dievaluasi pada test set 2.160 sampel dengan akurasi **0,8847** dan F1-macro **0,8846**.

**GridSearchCV:**

```python
GridSearchCV(
    estimator=pipeline,
    param_grid=params,
    cv=skv, refit='accuracy',
    scoring=scoring,

```
