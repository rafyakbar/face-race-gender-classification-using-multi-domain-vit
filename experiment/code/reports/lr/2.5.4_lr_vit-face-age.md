## 5. Hasil Cross-Validation

```python
grid_params = [
    {
        'scaler': [None, MinMaxScaler()],
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],
        'classifier': [LogisticRegression(random_state=42)],
        'classifier__C': [0.01, 0.1, 1, 10],
        'classifier__max_iter': [500, 1000],
        'classifier__solver': ['lbfgs', 'saga'],
    },
]

pipeline = Pipeline(steps=[
    ('scaler', None),
    ('pca', None),
    ('classifier', None)
])

skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy',
    'f1': 'f1_macro',
    'precision': 'precision_macro',
    'recall': 'recall_macro',
}

grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.6),
        verbose=1, error_score='raise',
        return_train_score=True
    )
    print(f'{key}: {len(ParameterGrid(params))} kombinasi')
```

**Output definisi grid:**

```
LogisticRegression: 96 kombinasi
```

**Parameter space (sesuai kode cell):**

| Parameter | Values |
|-----------|--------|
| `scaler` | `None`, `MinMaxScaler()` |
| `pca` | `None`, `PCA(n_components=0.5)`, `PCA(n_components=0.75)` |
| `classifier__C` | `0.01`, `0.1`, `1`, `10` |
| `classifier__max_iter` | `500`, `1000` |
| `classifier__solver` | `lbfgs`, `saga` |

- **Perhitungan kombinasi teoritis:** 2 (scaler) × 3 (pca) × 4 (C) × 2 (max_iter) × 2 (solver) = **96**

**CV settings:**
- **CV strategy:** Stratified 5-Fold (`StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`)
- **Refit metric:** `accuracy`
- **Scoring metrics:** `accuracy`, `f1_macro`, `precision_macro`, `recall_macro`
- **Parallel jobs:** `n_jobs = int(joblib.cpu_count() * 0.6)`, backend `threading`

> **⚠️ Diskrepansi yang tercatat (JANGAN DIABAIKAN):**
> Output `evaluation_results` dan `fold_results` yang tersimpan di notebook menunjukkan **`parameter_combinations = 270`** dan **best solver `newton-cg` + `max_iter` hingga 2000** — keduanya *tidak ada* dalam definisi `grid_params` di atas (`solver` hanya `lbfgs`/`saga`, `max_iter` hanya 500/1000). Ini mengindikasikan bahwa hasil evaluasi yang tersimpan berasal dari eksekusi sebelumnya dengan grid yang lebih luas (mis. `solver` mencakup `newton-cg`/`lbfgs`/`saga` dan `max_iter` mencakup 500/1000/2000, dengan kombinasi PCA/Scaler yang menghasilkan 270). Laporan ini melaporkan **kedua fakta apa adanya**: definisi kode menyebut 96, tetapi artefak hasil menyebut 270. Semua metrik di bawah dikutip verbatim dari output cell, bukan dari rekonstruksi grid.

**9. Key Observations**

1. **Best model:** Logistic Regression `C=0.1, solver=newton-cg, max_iter=500, pca=None, scaler=None` — akurasi test **91.62%** (1,979/2,160 benar).
2. **Dual-domain 1536-dim efektif:** Tanpa PCA dan tanpa scaler sudah optimal; feature concatenation face+age mempertahankan informasi diskriminatif penuh. Kombinasi PCA di bottom 4 menurunkan mean CV ke 86.41%.
3. **Regularisasi moderat optimal:** `C=0.1` mendominasi top 4; `C=0.01` dengan PCA berada di bottom — regularisasi terlalu kuat mengorbankan kapasitas model.
4. **Solver trade-off:** `newton-cg` dominan di top 3 dengan akurasi identik (0.9153) untuk max_iter 500/1000/2000; varian `lbfgs` (rank 4) hanya 0.0001 di bawah namun 4–7 detik lebih lambat per fold.
5. **Kelas terbaik/terburuk:** `Black_Males` tertinggi (F1 0.9436, OvR 98.10%, recall 95.28%, precision 0.9346); `White_Females` terendah (F1 0.8982, recall 89.44%). `Asian_Females` memiliki precision tertinggi (0.9350).
6. **Pola confusion:** Error terkonsentrasi pada White ↔ Asian/Male-Female lintas ras; `Black_Males` hampir tidak pernah salah diklasifikasi sebagai `White_Females`/`White_Males` (0 error ke White_Females/White_Males pada baris Black_Males).
7. **Grid vs artefak:** Kode notebook mendeklarasikan 96 kombinasi, tetapi artefak hasil menyimpan 270 kombinasi dengan `solver=newton-cg` dan `max_iter=2000` — laporan ini mengutip keduanya verbatim dan menandai inkonsistensi sebagai temuan, bukan koreksi diam-diam.
8. **Biaya komputasi:** Wall-clock 1h 59m 7s (parallel 60% CPU) vs total sekuensial 22h 58m 1s untuk mengevaluasi seluruh grid 5-fold. Train Time Mean bervariasi 6.6s (bottom) hingga 28.6s (top-4 lbfgs).
