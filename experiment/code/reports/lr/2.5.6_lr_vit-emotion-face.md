## 3. Load Fitur

```python
face_features = joblib.load('features/demogpairs_vit-face.pkl')
emotion_features = joblib.load('features/demogpairs_vit-emotion.pkl')
features = {}
for d in tqdm(data):
    key = d['image_path']
    features[key] = np.array(list(face_features[key]) + list(emotion_features[key]))
print('Jumlah fitur per gambar:', np.array(features[list(features.keys())[0]]).shape[0])
```

## 10. Key Observations

- **Best model:** Logistic Regression with C=0.1, lbfgs solver, no scaler, no PCA achieves **92.41% test accuracy**.
- **Class imbalance not an issue:** All 6 classes have exactly 360 test samples (balanced dataset).
- **Strongest class:** Black_Males (F1=0.9545, OvR Accuracy=98.47%).
- **Weakest class:** White_Males (F1=0.8976, OvR Accuracy=96.62%).
- **PCA hurts performance:** Configurations with PCA + MinMaxScaler (bottom 4) drop accuracy by ~6 percentage points compared to best.
- **Concatenated features improve over single models:** Using ViT face + emotion features (1536-dim) achieves 92.41% accuracy, significantly better than emotion-only (88.47%).
- **Total training time:** 22 hours 26 minutes 27 seconds (96 combinations × 5 folds + refit).
- **Grid search explored 270 total parameter combinations** (including train-time variants).
