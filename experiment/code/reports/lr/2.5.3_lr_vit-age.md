# Klasifikasi DemogPairs Menggunakan ViT (Umur) & Logistic Regression

**Notebook:** `2.5.3_lr_vit-age_demogpairs.ipynb`

---

## 1. Deskripsi

Notebook ini melakukan klasifikasi data DemogPairs menggunakan fitur ViT-Age dengan classifier Logistic Regression. Pipeline mencakup opsi scaling (MinMaxScaler) dan reduksi dimensi (PCA), dengan pencarian hyperparameter menggunakan GridSearchCV dan evaluasi stratified 5-fold cross-validation.

- **n_jobs:** `int(joblib.cpu_count() * 0.6)` (≈60% CPU)
