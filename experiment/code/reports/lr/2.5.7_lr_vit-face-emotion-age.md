## 5. Kombinasi Parameter (Grid Search Configuration)

```python
grid_params = [
    {
        'scaler': [None, MinMaxScaler()],
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],
        'classifier': [LogisticRegression(random_state=42)],
        'classifier__C': [0.01, 0.1, 1, 10],
        'classifier__max_iter': [500, 1000],
        'classifier__solver': ['lbfgs', 'saga'],
    },
]

pipeline = Pipeline(steps=[
    ('scaler', None),
    ('pca', None),
    ('classifier', None)
])

skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy',
    'f1': 'f1_macro',
    'precision': 'precision_macro',
    'recall': 'recall_macro',
}

grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.6),
        verbose=1, error_score='raise',
        return_train_score=True
    )
    print(f'{key}: {len(ParameterGrid(params))} kombinasi')
```

**Output definisi grid:**

```
LogisticRegression: 96 kombinasi
```

**Parameter space (sesuai kode cell):**

| Parameter | Values |
|-----------|--------|
| `scaler` | `None`, `MinMaxScaler()` |
| `pca` | `None`, `PCA(n_components=0.5)`, `PCA(n_components=0.75)` |
| `classifier__C` | `0.01`, `0.1`, `1`, `10` |
| `classifier__max_iter` | `500`, `1000` |
| `classifier__solver` | `lbfgs`, `saga` |

- **Perhitungan kombinasi teoritis:** 2 (scaler) × 3 (pca) × 4 (C) × 2 (max_iter) × 2 (solver) = **96**

**CV settings:**

- **CV strategy:** Stratified 5-Fold (`StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`)
- **Refit metric:** `accuracy`
- **Scoring metrics:** `accuracy`, `f1_macro`, `precision_macro`, `recall_macro`
- **Parallel jobs:** `n_jobs = int(joblib.cpu_count() * 0.6)`, backend `threading`

> **⚠️ Diskrepansi yang tercatat (JANGAN DIABAIKAN):**
> Output `evaluation_results` dan `fold_results` yang tersimpan di notebook menunjukkan **`parameter_combinations = 270`** dan **best solver `newton-cg` + `max_iter` 2000** — keduanya *tidak ada* dalam definisi `grid_params` di atas (`solver` hanya `lbfgs`/`saga`, `max_iter` hanya 500/1000). Ini mengindikasikan bahwa hasil evaluasi yang tersimpan berasal dari eksekusi sebelumnya dengan grid yang lebih luas (mis. `solver` mencakup `newton-cg`/`lbfgs`/`saga` dan `max_iter` mencakup 500/1000/2000, dengan kombinasi PCA/Scaler yang menghasilkan 270). Laporan ini melaporkan **kedua fakta apa adanya**: definisi kode menyebut 96, tetapi artefak hasil menyebut 270. Semua metrik di bawah dikutip verbatim dari output cell, bukan dari rekonstruksi grid.

## 9. Key Observations

1. **Best model:** Logistic Regression `C=0.1, solver=newton-cg, max_iter=500, pca=None, scaler=None` — akurasi test **92.73%** (2,003/2,160 benar).
2. **Tri-domain 2304-dim efektif:** Tanpa PCA dan tanpa scaler sudah optimal; penambahan PCA (terutama `n_components=0.5`) menurunkan mean CV ke ~87.4% (bottom 4).
3. **Regularisasi moderat optimal:** `C=0.1` mendominasi top 4; `C=0.01` dengan PCA berada di bottom.
4. **Solver trade-off:** `newton-cg` dan `lbfgs` jauh lebih cepat daripada `saga` pada akurasi yang hampir identik (rank 2 vs 4: 47.8s vs 207s untuk selisih 0.0003).
5. **Kelas terbaik/terburuk:** `Black_Males` tertinggi (F1 0.9558, OvR 98.52%, recall 96.11%); `White_Males` terendah (F1 0.9136, OvR 97.13%). `Asian_Females` memiliki precision tertinggi (0.9571).
6. **Pola confusion:** Error terkonsentrasi pada pasangan White ↔ Asian/Male-Female lintas ras, bukan intra-kelas; `Black_Males` hampir tidak pernah salah diklasifikasi sebagai `White_*` (0 error ke White_Females/White_Males).
7. **Grid vs artefak:** Kode notebook mendeklarasikan 96 kombinasi, tetapi artefak hasil menyimpan 270 kombinasi dengan `solver=newton-cg` dan `max_iter=2000` — laporan ini mengutip keduanya verbatim dan menandai inkonsistensi sebagai temuan, bukan koreksi diam-diam.
8. **Biaya komputasi:** Wall-clock 3h 25m 58s (parallel 60% CPU) vs total sekuensial 1d 15h 20m 43s untuk mengevaluasi seluruh grid 5-fold.
