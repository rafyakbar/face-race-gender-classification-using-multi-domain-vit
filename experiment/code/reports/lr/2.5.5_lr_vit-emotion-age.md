# Klasifikasi DemogPairs Menggunakan ViT (Emosi dan Umur) & Logistic Regression

> **Notebook:** `2.5.5_lr_vit-emotion-age_demogpairs.ipynb`
> **Dataset:** DemogPairs (CWF) — 10,800 gambar, 6 kelas demografi
> **Fitur:** ViT-Emotion + ViT-Age (concatenated, 1,536 dimensi)
> **Classifier:** Logistic Regression (GridSearchCV + Stratified 5-Fold CV)

## 1. Deskripsi

Notebook ini melakukan klasifikasi data DemogPairs menggunakan fitur gabungan dari dua model Vision Transformer — **ViT-Emotion** dan **ViT-Age** — dengan classifier **Logistic Regression**. Pipeline mencakup opsi scaling (`MinMaxScaler`) dan reduksi dimensi (`PCA`), dengan pencarian hyperparameter menggunakan `GridSearchCV`.

## 6. Kombinasi Parameter (Grid Search Configuration)

```python
grid_params = [
    {
        'scaler': [None, MinMaxScaler()],
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],
        
        'classifier': [LogisticRegression(random_state=42)],
        'classifier__C': [0.01, 0.1, 1, 10],
        'classifier__max_iter': [500, 1000],
        'classifier__solver': ['lbfgs', 'saga'],
    },
]

pipeline = Pipeline(steps=[
    ('scaler', None),
    ('pca', None),
    ('classifier', None)
])

skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy', 
    'f1': 'f1_macro', 
    'precision': 'precision_macro', 
    'recall': 'recall_macro',
}

grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.6),
        verbose=1, error_score='raise',
        return_train_score=True
    )
    print(f'{key}: {len(ParameterGrid(params))} kombinasi')
```

## 13. Key Observations

1. **Best model:** Logistic Regression dengan `C=0.1`, `solver=lbfgs`, `max_iter=500`, **tanpa scaler dan tanpa PCA** — mencapai **90.51% accuracy** pada test set (2,160 sampel).
2. **Tanpa preprocessing terbaik:** Baik `scaler=None` maupun `pca=None` dominan di top 4 — MinMaxScaler dan PCA tidak membantu untuk fitur emotion-age 1,536 dimensi pada LR.
3. **Regularisasi menengah optimal:** `C=0.1` mengungguli `C=0.01` (underfit, ~81% bottom) maupun `C=1/10` (tidak muncul di top 4 yang ditampilkan).
4. **Solver stabil:** `lbfgs` dan `newton-cg` menghasilkan akurasi identik (~0.8926 mean CV); `saga` muncul di bottom dengan PCA+scaler — mengindikasikan interaksi negatif antara `saga` dan reduksi dimensi.
5. **max_iter tidak kritis:** 500, 1000, dan 2000 menghasilkan `Accuracy Mean` identik (0.8926) untuk `lbfgs + C=0.1 + None/None` — konvergensi tercapai sebelum 500 iterasi.
6. **Kelas terkuat:** `Black_Males` (Precision 0.9463, F1 0.9384, OvR Accuracy 0.9796) — paling mudah dibedakan oleh fitur emotion-age.
7. **Kelas terlemah:** `White_Males` (Precision 0.8722, Recall 0.8722, F1 0.8722, OvR 0.9574) dan `White_Females` (F1 0.8821) — confusion tertinggi dengan `Black_Females` (17+22 misclass) dan antar-White (18 misclass White_Males→White_Females, 15 sebaliknya).
8. **Pola confusion:** Kesalahan dominan bersifat **cross-race** dalam gender yang sama: `Black_Females ↔ White_Males` (22+17), `White_Females ↔ Asian_Males` (16), `White_Males ↔ White_Females` (18), `Black_Males ↔ Black_Females` (11).
9. **PCA merugikan:** Bottom 4 semua menggunakan `pca='PCA'` (n_components=0.5 atau 0.75 implisit) + `MinMaxScaler` + `C=0.01` — akurasi anjlok ke 81.08% mean CV.
10. **Biaya komputasi:** Grid search membutuhkan **2 jam 3 menit wall-clock (parallel, 60% CPU)** atau **23 jam 49 menit total sekuensial** untuk 96 (tercetak) / 270 (tercatat) kombinasi × 5 fold — relatif efisien untuk Logistic Regression dibanding SVM/RF.
11. **Konsistensi CV vs Test:** Mean CV top 0.8926 vs Test 0.9051 — gap +1.25 poin menunjukkan generalisasi baik; tidak ada overfitting signifikan.
12. **Fitur emotion-age kompetitif:** Dengan hanya 1,536 dimensi (vs 2,304 face+emotion+age), akurasi 90.51% mendekati kombinasi face-involved — menunjukkan informasi emosi dan umur cukup diskriminatif untuk demografi ras-gender.
