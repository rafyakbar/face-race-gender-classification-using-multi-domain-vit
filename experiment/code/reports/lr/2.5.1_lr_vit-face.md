# Klasifikasi DemogPairs Menggunakan ViT (Wajah) & Logistic Regression

**Notebook:** `2.5.1_lr_vit-face_demogpairs.ipynb`

---

## 1. Deskripsi

Notebook ini melakukan klasifikasi data DemogPairs menggunakan fitur ViT-Face dengan classifier Logistic Regression. Pipeline mencakup opsi scaling (MinMaxScaler) dan reduksi dimensi (PCA), dengan pencarian hyperparameter menggunakan GridSearchCV dan evaluasi stratified 5-fold cross-validation.

---

## 2. Dataset

**Total sampel:** 10.800 gambar  
**Jumlah kelas:** 6 (demografi berdasarkan ras dan gender)  
**Database:** CWF (CelebFaces-in-the-Wild)

| Kelas | Label | label_idx |
|---|---|---|
| Asian_Females | Asian_Females | 5 |
| Asian_Males | Asian_Males | 2 |
| Black_Females | Black_Females | 4 |
| Black_Males | Black_Males | 0 |
| White_Females | White_Females | 1 |
| White_Males | White_Males | 3 |

Distribusi seimbang: ±1.800 sampel per kelas (10.800 / 6).

**Split data:**
- **Train:** 8.640 sampel (80%)
- **Test:** 2.160 sampel (20%)
- Stratified split, `random_state=42`

```python
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, stratify=y, random_state=42)
```

### Cross-Validation

- **Metode:** StratifiedKFold
- **Jumlah fold:** 5
- **Shuffle:** True, `random_state=42`
- **Scoring:** Accuracy, F1 (macro), Precision (macro), Recall (macro)
- **Refit berdasarkan:** Accuracy
- **n_jobs:** `int(joblib.cpu_count() * 0.6)` (≈60% CPU)
- **Backend paralel:** `joblib.parallel_backend('threading')`

```python
skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy',

}
```
