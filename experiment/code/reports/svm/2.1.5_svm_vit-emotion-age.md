> **Notebook:** `2.1.5_svm_vit-emotion-age_demogpairs.ipynb` — Dual-domain ViT-Emotion + ViT-Age (1.536 dimensi) dengan classifier SVM (SVC)
> **Report dihasilkan otomatis dari output notebook — tanpa fabrikasi data. Semua nilai dikutip verbatim dari eksekusi cell.**

---

## 1. Konfigurasi Eksperimen

Notebook ini melakukan klasifikasi dataset **DemogPairs** (10.800 gambar, 6 kelas intersectional 3 Ras × 2 Gender) menggunakan fitur gabungan dari dua model **Vision Transformer (ViT)** — **ViT-Emotion** dan **ViT-Age** — yang dikonkatenasi menjadi vektor **1.536 dimensi** per gambar, kemudian diklasifikasikan dengan **Support Vector Machine (SVM / SVC)** yang dioptimasi via **GridSearchCV** dengan validasi silang **StratifiedKFold 5-fold** (`shuffle=True, random_state=42`, `refit='accuracy'`, scoring `accuracy`/`f1_macro`/`precision_macro`/`recall_macro`). Split data 80/20 stratified (`random_state=42`) menghasilkan 8.640 train / 2.160 test; pencarian meliputi **288 kombinasi hyperparameter**; model terbaik mencapai **Accuracy 0.9208** dan **F1-macro 0.9209** pada test set.

### 4.3 Metrik Global

```python
skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy', 
    'f1': 'f1_macro', 
    'precision': 'precision_macro', 
    'recall': 'recall_macro'
}
grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.8),
        verbose=1, error_score='raise',
        return_train_score=True
    )
    print(f'{key}: {len(ParameterGrid(params))} kombinasi')
```

def remove_keys(data, keys_to_remove, inplace=False):
    if not inplace:
        data = data.copy()
    for key in keys_to_remove:
        data.pop(key, None)
    return data
def dict_to_sentence(d):
    parts = [f"{k}={v}" for k, v in d.items()]
    sentence = ", ".join(parts)
    return sentence

fold_displays = []
for r in [remove_keys(r, ['No', 'F1 Score Mean', 'Precision Mean', 'Recall Mean', 'Train Time Mean']) for r in fold_results]:
