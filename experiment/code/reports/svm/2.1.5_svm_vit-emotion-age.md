## 5. Kombinasi Parameter (Grid Search Configuration)

```python
from sklearn.decomposition import PCA

grid_params = [
    {
        'scaler': [None, MinMaxScaler()],  # EN: scaling option / ID: opsi scaling
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],  # EN: with and without PCA / ID: dengan dan tanpa PCA
        
        'classifier': [SVC()],  # EN: SVM model / ID: model SVM
        
        'classifier__C': [0.01, 0.1, 1, 10],  # EN: regularization / ID: regularisasi
        'classifier__kernel': ['rbf', 'poly', 'linear'],  # EN: kernel types / ID: jenis kernel
        
        'classifier__gamma': ['scale', 'auto'],  # EN: gamma / ID: gamma
        'classifier__degree': [2, 3],  # EN: degree / ID: derajat
        
        'classifier__tol': [1e-3],  # EN: tolerance / ID: toleransi
        'classifier__probability': [True],  # EN: probability / ID: probabilitas
    },
]

pipeline = Pipeline(steps=[
    ('scaler', None),  # EN: optional scaler / ID: scaler opsional
    ('pca', None),     # EN: optional PCA / ID: PCA opsional
    ('classifier', None)  # EN: classifier / ID: classifier
])

skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy', 
    'f1': 'f1_macro', 
    'precision': 'precision_macro', 
    'recall': 'recall_macro'
}

grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.8),
        verbose=1, error_score='raise',
        return_train_score=True
    )
    print(f'{key}: {len(ParameterGrid(params))} kombinasi')
```

## 9. Key Observations

1. **Best model:** SVC dengan `C=10, kernel=rbf, gamma=scale, degree=2` — **tanpa scaler, tanpa PCA** — mencapai **92.08% accuracy** pada test set (2,160 sampel).
2. **Dual-domain emotion-age efektif:** 1,536 dimensi (768+768) menghasilkan 92.08% — lebih tinggi dari single-domain vit-emotion (90.19%) dan vit-age (87.64%), namun sedikit di bawah dual face-emotion (93.29%).
3. **Kelas terkuat:** Asian_Females (F1: 0.9512, OvR Accuracy: 0.9838, Recall: 0.9472) dan Black_Males (F1: 0.9484, OvR Accuracy: 0.9829) — paling mudah dibedakan oleh embedding emotion+age.
4. **Kelas terlemah:** White_Females (F1: 0.8958, Recall: 0.8833, OvR: 0.9657) — paling banyak salah klasifikasi, terutama ke White_Males (13), Asian_Males (16), dan Asian_Females (8).
5. **Confusion patterns:**
   - White_Females → Asian_Males: 16 kasus
   - Black_Females → White_Males: 15 kasus
   - White_Males → Black_Females: 14 kasus
   - Black_Males sangat baik (340/360 benar) — hanya 6 ke Asian_Females, 5 ke Asian_Males, 9 ke Black_Females
6. **PCA merugikan performa:** Kombinasi dengan PCA konsisten underperform; top 3 tanpa PCA (≈0.90), sedangkan rank 96–98 dengan PCA linear turun ke 0.87. Bottom 288 (poly+PCA) kolaps ke 0.349.
7. **Poly kernel kolaps pada C rendah + PCA:** Kombinasi terburuk `C=0.01–1, poly, gamma=auto, pca=PCA, scaler=MinMaxScaler` hanya ~34.9% accuracy (Bottom 3), mendekati random untuk 6 kelas (~16.7%) namun masih sangat rendah.
8. **RBF dominan:** Semua Top 3 menggunakan kernel `rbf` dengan `C=10, gamma=scale`; MinMaxScaler memberikan variasi marginal (rank 3: 0.8997 vs rank 1–2: 0.9017).
9. **Degree tidak berpengaruh pada RBF:** Degree=2 vs 3 pada kernel rbf menghasilkan hasil identik (rank 1 vs 2: mean 0.9017 identik), karena `degree` hanya relevan untuk kernel `poly`.
10. **Biaya training sangat tinggi:** Grid search 288 kombinasi × 5-fold = 1,440 fits memerlukan **7h 22m wall-clock** (80% CPU paralel) atau setara **3 hari 9 jam** secara sequential — dual-domain 1,536 dimensi lebih mahal dari single-domain namun lebih murah dari tri-domain 2,304 dimensi.
11. **Reproduksibilitas:** `random_state=42` pada `train_test_split` dan `StratifiedKFold`, `tqdm` untuk ekstraksi fitur, `joblib` threading — semua artefak tersimpan di `models/`, `results/`, `images/`.
