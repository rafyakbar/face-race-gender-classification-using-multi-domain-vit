> **Notebook:** `2.1.2_svm_vit-emotion_demogpairs.ipynb` — Klasifikasi 6 kelas demografi (ras × gender) pada dataset DemogPairs menggunakan fitur **Vision Transformer (ViT) pre-trained Emosi** dan classifier **Support Vector Machine (SVC)** dengan GridSearchCV 5-Fold.

```python
pipeline = Pipeline(steps=[
```
