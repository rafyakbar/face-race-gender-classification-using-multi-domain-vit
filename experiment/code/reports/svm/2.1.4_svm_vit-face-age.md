## 5. Kombinasi Parameter (Grid Search Configuration)

```python
from sklearn.decomposition import PCA

grid_params = [
    {
        'scaler': [None, MinMaxScaler()],  # EN: scaling option / ID: opsi scaling
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],  # EN: with and without PCA / ID: dengan dan tanpa PCA
        
        'classifier': [SVC()],  # EN: SVM model / ID: model SVM
        
        'classifier__C': [0.01, 0.1, 1, 10],  # EN: regularization / ID: regularisasi
        'classifier__kernel': ['rbf', 'poly', 'linear'],  # EN: kernel types / ID: jenis kernel
        
        'classifier__gamma': ['scale', 'auto'],  # EN: gamma / ID: gamma
        'classifier__degree': [2, 3],  # EN: degree / ID: derajat
        
        'classifier__tol': [1e-3],  # EN: tolerance / ID: toleransi
        'classifier__probability': [True],  # EN: probability / ID: probabilitas
    },
]

pipeline = Pipeline(steps=[
    ('scaler', None),  # EN: optional scaler / ID: scaler opsional
    ('pca', None),     # EN: optional PCA / ID: PCA opsional
    ('classifier', None)  # EN: classifier / ID: classifier
])

skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy', 
    'f1': 'f1_macro', 
    'precision': 'precision_macro', 
    'recall': 'recall_macro'
}

grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.6),
        verbose=1, error_score='raise',
        return_train_score=True
    )
    print(f'{key}: {len(ParameterGrid(params))} kombinasi')
```

## 9. Key Observations

1. **Best model dual-domain (Face+Age):** SVC dengan `C=10, kernel=poly, degree=2, gamma=scale`, tanpa scaler dan tanpa PCA — akurasi **92.55%** pada test set (2160 sampel).
2. **Peningkatan dari single-domain:** Dual-domain 92.55% melampaui vit-face saja (~90.83% pada 2.1.1) dan vit-age saja (~87.64% pada 2.1.3), menunjukkan komplementaritas fitur wajah dan umur. Poly kernel degree=2 menjadi pemenang di sini (berbeda dari RBF yang menang di single-domain), mengindikasikan interaksi fitur lebih kompleks pada dimensi 1536.
3. **Class terbaik:** Black_Males (F1: 0.9488, Recall: 0.9528, OvR Accuracy: 0.9829) — paling mudah dibedakan, hanya 17 kesalahan dari 360 sampel.
4. **Class terlemah:** White_Females (F1: 0.9045, Recall: 0.8944, OvR Accuracy: 0.9685) — confusion tertinggi, terutama 14 kasus salah sebagai Asian_Males dan 10 sebagai Asian_Females.
5. **Pola confusion:** Asian_Males ↔ White_Females/White_Males masih menonjol (9→White_Females, 15→White_Males); Black_Females ↔ White_Males (9 kasus); White_Males ↔ Asian_Males/Black_Females (12 dan 7 kasus).
6. **PCA merugikan pada dimensi tinggi:** Semua top-3 tanpa PCA (mean CV ~92.2–92.3%); konfigurasi dengan `PCA(n_components=0.5/0.75)` turun ke ~89.4% di rank 96–98 dan hingga ~55.8% di bottom.
7. **Poly + PCA + MinMaxScaler + C kecil = collapse:** Kombinasi terburuk (C=0.01, poly, gamma=auto, PCA, MinMaxScaler) hanya 55.83% — masih di atas random (16.6% untuk 6 kelas) tapi jauh di bawah baseline, berbeda dari single-domain emotion yang bisa drop ke ~29%.
8. **Degree tidak sensitif pada kernel RBF:** Di peringkat 2 dan 3, degree=2 vs degree=3 dengan RBF menghasilkan skor identik (Mean 0.9222, fold identik), sama seperti pada vit-face dan vit-emotion.
9. **Training cost sangat tinggi:** Grid search 288 kombinasi × 5-fold pada fitur 1536-dim membutuhkan ~6 jam wall-clock (parallel, 60% CPU) atau ~50 jam sekuensial (≈2 hari 2 jam total termasuk refit) — lebih mahal dari single-domain 768-dim (2.1.1: ~23 jam total; 2.1.3 vit-age: ~35 jam total).
10. **Tidak ada scaling benefit:** Best model tanpa scaler mengungguli varian dengan MinMaxScaler, konsisten dengan temuan single-domain RBF.
