# Klasifikasi DemogPairs Menggunakan Fitur ViT (Umur) & SVM

> **Notebook:** `2.1.3_svm_vit-age_demogpairs.ipynb` — Klasifikasi DemogPairs Menggunakan Fitur ViT (Umur) & SVM

Laporan ini merangkum eksperimen klasifikasi 6 kelas pasangan demografi (Asian_Females, Asian_Males, Black_Females, Black_Males, White_Females, White_Males) pada dataset DemogPairs menggunakan fitur embedding Vision Transformer (ViT) dari model pre-trained **umur (age)** dengan dimensi 768 dan classifier **Support Vector Machine (SVM)**. Seluruh nilai pada laporan ini diambil langsung dari output eksekusi notebook tanpa modifikasi atau fabrikasi. Grid search dilakukan dengan pipeline `[Scaler] → [PCA] → [SVC]` sebanyak 288 kombinasi dan validasi silang 5-fold, kemudian model terbaik dievaluasi pada test set terpisah (2.160 sampel).

### 1.4 Pipeline & Grid Search

```python
from sklearn.decomposition import PCA

grid_params = [
    {
        'scaler': [None, MinMaxScaler()],
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],
        'classifier': [SVC()],
        'classifier__C': [0.01, 0.1, 1, 10],
        'classifier__kernel': ['rbf', 'poly', 'linear'],
        'classifier__gamma': ['scale', 'auto'],
        'classifier__degree': [2, 3],
        'classifier__tol': [1e-3],
        'classifier__probability': [True],
    },
]

pipeline = Pipeline(steps=[
    ('scaler', None),
    ('pca', None),
    ('classifier', None)
])

skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy',
    'f1': 'f1_macro',
    'precision': 'precision_macro',
    'recall': 'recall_macro'
}

grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.6),
        verbose=1, error_score='raise',
        return_train_score=True
    )
    print(f'{key}: {len(ParameterGrid(params))} kombinasi')
```

## Bab 5 — Cross-Validation (5-Fold Stratified)

Grid search mengevaluasi **288 kombinasi** dengan `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`. Tabel di bawah diringkas dari `fold_results` yang diurutkan menurun berdasarkan **Mean Accuracy** (rata-rata 5 fold). Kode pembentuk tabel:

```python
def remove_keys(data, keys_to_remove, inplace=False):
    if not inplace:
        data = data.copy()
    for key in keys_to_remove:
        data.pop(key, None)
    return data

def dict_to_sentence(d):
    parts = [f"{k}={v}" for k, v in d.items()]
    sentence = ", ".join(parts)
    return sentence

fold_displays = []
for r in [remove_keys(r, ['No', 'F1 Score Mean', 'Precision Mean', 'Recall Mean', 'Train Time Mean']) for r in fold_results]:
    r['Params'] = dict_to_sentence(remove_keys(r['Params'], ['classifier'])).replace('classifier__', '')
    r['Mean'] = r['Accuracy Mean']
    del r['Accuracy Mean']
    fold_displays.append(r)
fold_displays = [{'No': idx + 1, **r} for idx, r in enumerate(sorted(fold_displays, key=lambda x: x['Mean'], reverse=True))]
_dtable = u.display_table(fold_displays, n_items=[3, 3, 3, 3], column_widths=['5%', '65%', '5%', '5%', '5%', '5%', '5%', '5%'])
```
