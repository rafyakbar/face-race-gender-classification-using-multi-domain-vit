# Klasifikasi DemogPairs Menggunakan ViT (Umur) & Random Forest

Eksperimen ini menggunakan fitur embedding dari Vision Transformer (ViT) yang dilatih pada tugas prediksi umur untuk mengklasifikasi 6 kelas demografis (Asian_Females, Asian_Males, Black_Females, Black_Males, White_Females, White_Males) pada dataset DemogPairs. Klasifikasi dilakukan menggunakan Random Forest dengan GridSearchCV untuk pencarian hyperparameter terbaik.

## 1. Konfigurasi Eksperimen

- **Fitur**: ViT Age (`demogpairs_vit-age.pkl`) — 768 dimensi per gambar
- **Dataset**: DemogPairs — 10.800 gambar (6 kelas × 1.800)
- **Split**: 80/20 (8.640 train / 2.160 test) dengan stratified split
- **Classifier**: Random Forest
- **Pipeline**: Scaler (None/MinMaxScaler) → PCA (None/0.5/0.75) → Random Forest
- **Cross-Validation**: Stratified 5-Fold
- **Kombinasi Parameter**: 288
  - `n_estimators`: [100, 200]
  - `max_depth`: [None, 20, 30]
  - `min_samples_split`: [2, 5]
  - `min_samples_leaf`: [1, 2]
  - `max_features`: ['sqrt', 'log2']
  - `scaler`: [None, MinMaxScaler]
  - `pca`: [None, PCA(0.5), PCA(0.75)]
