# Klasifikasi DemogPairs Menggunakan Fitur ViT (Wajah, Emosi, dan Umur) dengan Gaussian Naive Bayes

## 1. Konfigurasi Eksperimen

**Dataset — DemogPairs:**
- Sumber: `u.load_demogpairs()` — 10.800 citra (`[10800 rows x 5 columns]`), kolom `db_code`, `image_path`, `full_path`, `label`, `label_idx`.
- Database: `CWF`.
- Kelas (6): `Asian_Females`, `Asian_Males`, `Black_Females`, `Black_Males`, `White_Females`, `White_Males` — urutan evaluasi `target_names = u.demogpairs_classes` sesuai `classification_report`.
- Distribusi seimbang: tiap kelas ~1.800 total; pada `test` tiap kelas `support = 360` (2160 / 6).

**Fitur — ViT Wajah + Emosi + Umur (konkatenasi):**
- File:
  - `features/demogpairs_vit-face.pkl` (`joblib.load`)
  - `features/demogpairs_vit-emotion.pkl` (`joblib.load`)
  - `features/demogpairs_vit-age.pkl` (`joblib.load`)
- Kode konkatenasi:
```python
face_features = joblib.load('features/demogpairs_vit-face.pkl')
emotion_features = joblib.load('features/demogpairs_vit-emotion.pkl')
age_features = joblib.load('features/demogpairs_vit-age.pkl')
features[key] = np.array(list(face_features[key]) + list(emotion_features[key]) + list(age_features[key]))
```
- Dimensi: `2304` per gambar — output notebook: `Jumlah fitur per gambar: 2304` dan `100%|████████████████████████████████| 10800/10800 [00:01<00:00, 7264.79it/s]`.

**Split Data:**
```python
X = np.array([features[d['image_path']] for d in data])
```

**Pipeline:**
```python
pipeline = Pipeline(steps=[('scaler', None), ('pca', None), ('classifier', None)])
```
- Urutan: `Scaler (opsional)` → `PCA (opsional)` → `GaussianNB`.

**Grid Pencarian Hyperparameter:**
```python

    'scaler': [None, MinMaxScaler()],

```

|---|---|
| `scaler` | `None`, `MinMaxScaler()` |
| `pca` | `None`, `PCA(n_components=0.5)`, `PCA(n_components=0.75)` |
| `classifier` | `GaussianNB()` |
| `classifier__var_smoothing` | 40 nilai `np.logspace(-9, 2, 40)` |

- Total kombinasi: **240** (2 × 3 × 40) — output: `GaussianNB: 240 kombinasi`.

**Cross-Validation & Scoring:**
```python
skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
```

- Scoring: `accuracy`, `f1_macro`, `precision_macro`, `recall_macro`; `refit='accuracy'`.
- Evaluasi: `u.evaluate_models(..., target_names=u.demogpairs_classes, model_prefix='models/clf_demogpairs_gnb_vit-face-emotion-age_', results_path='results/demogpairs_gnb_vit-face-emotion-age_')` — model tersimpan `models/clf_demogpairs_gnb_vit-face-emotion-age_GaussianNB.pkl`.
