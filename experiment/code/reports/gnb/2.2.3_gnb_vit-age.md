## 5. Hasil Cross-Validation

```python
var_smoothing_values = np.logspace(-9, 2, 40)  # dari 1e-9 sampai 1e2, 40 nilai

grid_params = [
    {
        'scaler': [None, MinMaxScaler()],
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],
        'classifier': [GaussianNB()],
        'classifier__var_smoothing': var_smoothing_values
    },
]

pipeline = Pipeline(steps=[
    ('scaler', None),
    ('pca', None),
    ('classifier', None)
])

skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy',
    'f1': 'f1_macro',
    'precision': 'precision_macro',
    'recall': 'recall_macro'
}
grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.6),
        verbose=1, error_score='raise',
        return_train_score=True
    )
    print(f'{key}: {len(ParameterGrid(params))} kombinasi')
```

**9. Key Observations**

1. **Best model:** GaussianNB dengan `var_smoothing=0.000437547937507418`, `PCA(n_components=0.75)` + `MinMaxScaler` — pipeline `MinMaxScaler → PCA(0.75) → GaussianNB`.
2. **Overall accuracy:** 69.63% pada test set (2,160 sampel) — terendah di keluarga GNB ViT, mengindikasikan embedding umur (ViT-Age) kurang diskriminatif untuk atribut ras–gender dibanding ViT-Face (82.69%) dan ViT-Emotion (73.38%).
3. **Class balance:** Semua 6 pasangan demografis seimbang (360 test sampel per kelas; stratifikasi terjaga).
4. **Best-performing class (F1):** Black_Males (F1: 0.7359, Recall: 0.7778) — diikuti Asian_Males (0.7210) dan White_Males (0.7119).
5. **Worst-performing class (F1):** Black_Females (F1: 0.6459, Precision: 0.6921, Recall: 0.6056) — terendah, disusul White_Females (0.6817).
6. **OvR tertinggi:** Black_Males (OvR Acc 90.69%) dan White_Males/Asian_Males (OvR ~90.3%); Asian_Females OvR terendah 88.75% dengan precision terendah 0.6512.
7. **Confusion patterns:**
   - Asian_Females paling sering tertukar ke Black_Males (57) dan White_Females (26).
   - White_Females paling sering tertukar ke Asian_Males (52) dan Asian_Females (38).
   - Black_Females banyak tertukar ke White_Males (46) dan Asian_Females (42) — intra-race dan cross-race confusion tinggi.
   - Asian_Males relatif kuat (recall 0.75) namun 29 kasusnya tertukar sebagai White_Males.
   - Black_Males terkuat (recall 0.7778) tetapi masih 27 kasus diprediksi sebagai Asian_Females.
8. **Efek PCA:** Semua top-4 kombinasi terbaik menggunakan `pca: PCA(n_components=0.75)` + `MinMaxScaler`; tanpa PCA tidak masuk top-4 bahkan mendominasi bottom — reduksi dimensi yang mempertahankan 75% varians membantu GNB mengestimasi kovarians pada 768-dim.
9. **Efek var_smoothing:** Nilai optimal sangat kecil (~4e-04); nilai besar (52–100) kolaps ke ~38.90% akurasi — mendekati 6-class chance (16.7%) namun jauh di atasnya; smoothing berlebihan menghancurkan pemisahan distribusi Gaussian. Sweet spot di ~1e-05–4e-04.
10. **Efek Scaler:** MinMaxScaler membantu GNB untuk fitur ViT-Age — semua top-4 menggunakan MinMaxScaler; bottom tanpa PCA menunjukkan variasi scaler tidak menyelamatkan model jika smoothing terlalu besar.
11. **Training cost:** Grid search 240 kombinasi × 5 folds = 1,200 fits diselesaikan dalam ~7m 55s wall-clock (parallel 60% CPU) atau ~40m 10s sequential; jauh lebih murah dibanding SVM vit-age (jam-an).
12. **Gap CV vs Test:** Mean CV accuracy terbaik 0.6919 vs Test 0.6963 — selisih hanya +0.0044, menandakan tidak ada overfit signifikan pada pemilihan hyperparameter terbaik.
