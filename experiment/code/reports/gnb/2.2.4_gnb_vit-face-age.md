## 1. Konfigurasi Eksperimen

| Aspek | Nilai / Detail (dari output notebook) |
|---|---|
| **Dataset** | DemogPairs — `u.load_demogpairs()` → `pd.DataFrame` menampilkan `[10800 rows x 5 columns]` (kolom: `db_code`, `image_path`, `full_path`, `label`, `label_idx`; contoh `db_code=CWF`, `label=Asian_Females label_idx=5`, `White_Males label_idx=3`) |
| **Kelas** | 6 kelas interseksional: `Asian_Females`, `Asian_Males`, `Black_Females`, `Black_Males`, `White_Females`, `White_Males` (masing-masing 1.800 gambar, seimbang; `u.demogpairs_classes` sebagai `target_names`) |
| **Fitur** | Gabungan ViT-Face + ViT-Age: `features/demogpairs_vit-face.pkl` dan `features/demogpairs_vit-age.pkl` dikonkatenasi per `image_path` via `np.array(list(face_features[key]) + list(age_features[key]))` (loop `tqdm` 10.800 iterasi) |
| **Jumlah fitur per gambar** | **1536** — output cell *Load Fitur*: `Jumlah fitur per gambar: 1536` (768 Face + 768 Age) |
| **Split data** | `train_test_split(test_size=0.2, stratify=y, random_state=42)` → **8640 train / 2160 test** (stratified 80/20). Output cell *Split Data*: `(8640, 2160)`. Test set seimbang: 360 sampel per kelas (kolom Support) |
| **Pipeline** | `imblearn.pipeline.Pipeline([('scaler', None), ('pca', None), ('classifier', None)])` — scaler dan PCA opsional |
| **Cross-validation** | `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)` |
| **Scoring** | `accuracy`, `f1_macro`, `precision_macro`, `recall_macro` (refit = `accuracy`) |
| **Parallel** | `joblib.parallel_backend('threading')`, `n_jobs = int(joblib.cpu_count() * 0.6)`, `verbose=1`, `error_score='raise'`, `return_train_score=True` |
| **Model prefix / results_path** | `model_prefix='models/clf_demogpairs_gnb_vit-face-age_'`, `results_path='results/demogpairs_gnb_vit-face-age_'` |
| **Gambar CM** | `images\cm_gnb_vit-face-age_GaussianNB.png` (dirender `width=600`) |

Rincian:
- **scaler**: 2 opsi — `None`, `MinMaxScaler()`

- **classifier**: `GaussianNB()`
- **classifier__var_smoothing**: 40 nilai log-spaced `1e-9` – `1e2` (`np.logspace(-9, 2, 40)`)

**Jumlah Kombinasi Parameter**

```

```

> Perhitungan: 2 × 3 × 40 = 240. Setiap kombinasi dievaluasi dengan 5-fold CV (1.200 fitting + 1 refit model terbaik pada seluruh train set).
