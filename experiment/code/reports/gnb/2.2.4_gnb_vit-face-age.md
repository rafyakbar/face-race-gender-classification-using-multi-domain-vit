# Klasifikasi DemogPairs Menggunakan ViT (Wajah dan Umur) & Gaussian Naive Bayes

Notebook `2.2.4_gnb_vit-face-age_demogpairs.ipynb` melakukan klasifikasi 6 kelas interseksional DemogPairs (3 ras × 2 gender) menggunakan fitur gabungan dari dua model Vision Transformer — ViT-Face (`demogpairs_vit-face.pkl`) dan ViT-Age (`demogpairs_vit-age.pkl`) — yang dikonkatenasi menjadi vektor 1.536-dimensi per gambar. Klasifikasi dilakukan dengan **Gaussian Naive Bayes (GaussianNB)** melalui pipeline `MinMaxScaler → PCA → GaussianNB` yang dioptimasi dengan `GridSearchCV` (240 kombinasi) dan **Stratified 5-Fold Cross-Validation** (`shuffle=True`, `random_state=42`). Evaluasi dilakukan pada test set 20% (2.160 sampel, 360 per kelas) dengan metrik accuracy, precision macro, recall macro, dan F1 macro. Model terbaik disimpan sebagai `models/clf_demogpairs_gnb_vit-face-age_GaussianNB.pkl` (`results/demogpairs_gnb_vit-face-age_`).

### 1.4 Pipeline & Grid Search

```python
var_smoothing_values = np.logspace(-9, 2, 40)  # 1e-9 s.d. 1e2, 40 nilai

grid_params = [
    {
        'scaler': [None, MinMaxScaler()],
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],
        'classifier': [GaussianNB()],
        'classifier__var_smoothing': var_smoothing_values
    },
]

pipeline = Pipeline(steps=[
    ('scaler', None),
    ('pca', None),
    ('classifier', None)
])

skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy',
    'f1': 'f1_macro',
    'precision': 'precision_macro',
    'recall': 'recall_macro',
}
GridSearchCV(
    estimator=pipeline,
    param_grid=params,
    cv=skv, refit='accuracy',
    scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.6),
    verbose=1, error_score='raise',
    return_train_score=True
)
```

| Parameter | Nilai yang diuji |
|---|---|
| `scaler` | `None`, `MinMaxScaler()` |
| `pca` | `None`, `PCA(n_components=0.5)`, `PCA(n_components=0.75)` |
| `classifier` | `GaussianNB()` |
| `classifier__var_smoothing` | 40 nilai logspace `1e-9` – `1e2` (`np.logspace(-9, 2, 40)`) |
| **Total kombinasi** | **240** — output: `GaussianNB: 240 kombinasi` |
| `Pipeline` | `imblearn.pipeline.Pipeline` : `scaler → pca → classifier` |
| `GridSearchCV` | `refit='accuracy'`, `n_jobs=int(cpu_count*0.6)`, `verbose=1` |
