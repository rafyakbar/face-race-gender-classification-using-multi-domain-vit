## 5. Kombinasi Parameter (Grid Search Configuration)

```python
var_smoothing_values = np.logspace(-9, 2, 40)  # dari 1e-9 sampai 1e2, 40 nilai

grid_params = [
    {
        'scaler': [None, MinMaxScaler()],
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],
        'classifier': [GaussianNB()],
        'classifier__var_smoothing': var_smoothing_values
    },
]

pipeline = Pipeline(steps=[
    ('scaler', None),
    ('pca', None),
    ('classifier', None)
])

skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy',
    'f1': 'f1_macro',
    'precision': 'precision_macro',
    'recall': 'recall_macro'
}

grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.6),
        verbose=1, error_score='raise',
        return_train_score=True
    )
    print(f'{key}: {len(ParameterGrid(params))} kombinasi')
```

## 9. Key Observations

1. **Best model:** GaussianNB dengan `var_smoothing=0.00307029062975785`, PCA aktif, tanpa MinMaxScaler — pipeline `PCA → GaussianNB`.
2. **Overall accuracy:** 73.38% pada test set (2,160 sampel) — secara signifikan di bawah SVM vit-emotion (90.19% pada report 2.1.2), menunjukkan keterbatasan asumsi distribusi Gaussian independen untuk fitur ViT emosi 768-dim.
3. **Class balance:** Semua 6 pasangan demografis seimbang (360 test sampel per kelas; stratifikasi terjaga).
4. **Best-performing class (F1):** Black_Males (F1: 0.7808, Recall: 0.8361) — diikuti White_Females (0.7441) dan Asian_Females (0.7564).
5. **Worst-performing class (F1):** Black_Females (F1: 0.6749, Precision: 0.6694) — terendah, disusul White_Males (F1: 0.6950, Recall: 0.6361 hanya).
6. **OvR tertinggi:** Asian_Females (OvR Acc 92.55%, Precision tertinggi 0.8306) namun recall rendah 0.6944 — model konservatif untuk kelas ini.
7. **Confusion patterns:**
   - Asian_Females paling sering tertukar ke White_Females (43) dan Black_Males (35).
   - White_Males paling sering tertukar ke Asian_Males (59) dan Black_Females (44).
   - Black_Females tertukar ke Black_Males (46) dan White_Males (32) — intra-race confusion masih dominan untuk Black.
   - Asian_Males hampir sempurna membedakan Asian_Females (0 salah ke AF), tapi bocor ke White_Males (23) dan White_Females (19).
8. **Efek PCA:** Semua top-4 kombinasi terbaik menggunakan `pca: PCA` + `scaler: None` dengan var_smoothing di rentang 2e-04–5e-03; tanpa PCA tidak masuk top-4, mengindikasikan reduksi dimensi membantu GNB (berbeda dengan SVM vit-emotion di mana PCA justru merugikan).
9. **Efek var_smoothing:** Nilai sangat besar (≥ 27, hingga 100) kolaps ke ~48–49% akurasi — mendekati random untuk 6 kelas (16.7%) namun jauh di atasnya; sweet spot di ~0.001–0.006. Nilai ekstrem besar meningkatkan variance smoothing secara berlebihan sehingga distribusi kelas menjadi tidak diskriminatif, namun Precision Mean tetap tinggi (~0.63) mengindikasikan prediksi bias ke mayoritas.
10. **Efek Scaler:** MinMaxScaler + PCA + var_smoothing=100 menempati rank 237 (0.4910), hanya sedikit lebih baik dari tanpa scaler — scaling tidak membantu GNB untuk fitur ViT emosi yang sudah ternormalisasi.
11. **Training cost:** Grid search 240 kombinasi × 5 folds = 1,200 fits diselesaikan dalam ~7m 56s wall-clock (parallel 60% CPU) atau ~38m 7s sequential; jauh lebih murah dibanding SVM vit-emotion (3h 56m wall / 32h sequential).
12. **Gap CV vs Test:** Mean CV accuracy terbaik 0.7311 vs Test 0.7338 — selisih hanya +0.0027, menandakan tidak ada overfit signifikan pada pemilihan hyperparameter terbaik.
