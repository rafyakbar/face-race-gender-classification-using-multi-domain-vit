## 1. Deskripsi

Notebook ini melakukan klasifikasi data **DemogPairs** menggunakan fitur **ViT-Face** (Vision Transformer pra-latih untuk wajah) dengan classifier **Gaussian Naive Bayes (GaussianNB)**. Pipeline mencakup opsi scaling (`MinMaxScaler`) dan reduksi dimensi (`PCA`), dengan pencarian hyperparameter menggunakan `GridSearchCV` dan evaluasi 5-Fold Stratified Cross-Validation.

### 5.2 Parameter Grid (GaussianNB)

```python
var_smoothing_values = np.logspace(-9, 2, 40)  # dari 1e-9 sampai 1e2, 40 nilai

grid_params = [
    {
        'scaler': [None, MinMaxScaler()],
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],
        'classifier': [GaussianNB()],
        'classifier__var_smoothing': var_smoothing_values
    },
]
```

| Parameter | Nilai yang Diuji |
|-----------|------------------|
| `scaler` | `None`, `MinMaxScaler()` |
| `pca` | `None`, `PCA(n_components=0.5)`, `PCA(n_components=0.75)` |
| `classifier` | `GaussianNB()` |
| `classifier__var_smoothing` | 40 nilai log-spaced dari `1e-9` sampai `1e2` (`np.logspace(-9, 2, 40)`) |

**Total kombinasi parameter:** **240** (2 × 3 × 40) — output notebook: `GaussianNB: 240 kombinasi`

> Nilai `var_smoothing` terbaik berada pada indeks ke-27 dari grid: `0.04124626382901348`.

### 5.3 Cross-Validation & Scoring

```python
skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy',
    'f1': 'f1_macro',
    'precision': 'precision_macro',
    'recall': 'recall_macro'
}
grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.6),
        verbose=1, error_score='raise',
        return_train_score=True
    )
```

- **Metode:** StratifiedKFold, 5 folds, `shuffle=True`, `random_state=42`
- **Scoring:** `accuracy`, `f1_macro`, `precision_macro`, `recall_macro`
- **Refit berdasarkan:** `accuracy`
- **Backend paralel:** `joblib.parallel_backend('threading')`, `n_jobs = int(cpu_count * 0.6)`

## 13. Observasi Kunci

1. **Performa moderat untuk GNB:** 82.69% accuracy dengan var_smoothing≈0.041, MinMaxScaler + PCA(0.75). Lebih rendah dari SVM pada fitur yang sama (≈90.83% pada laporan SVM).
2. **Kelas terkuat:** Asian_Males (F1 0.8867, recall 0.8917) dan Black_Males (F1 0.8820, recall 0.9028).
3. **Kelas terlemah:** White_Females (F1 0.7583, recall hanya 0.6972) — 109 dari 360 White_Females salah klasifikasi, terutama ke Asian_Females (48) dan Asian_Males (23). Black_Females juga lemah (F1 0.7830).
4. **PCA 0.75 membantu:** Top 3 semua menggunakan PCA 0.75 + MinMaxScaler; PCA 0.5 mendominasi bottom 3, menunjukkan retensi 75% varians lebih optimal untuk GNB pada fitur 768-dim.
5. **Var_smoothing sensitif:** Nilai terlalu besar (>27) menurunkan akurasi hingga 80.56%; nilai kecil-menengah (~0.04–0.15) optimal.
6. **Waktu pelatihan ringan:** GNB jauh lebih cepat (40 menit total sekuensial) dibanding SVM pada fitur sama (jam-an), karena tanpa optimasi margin.
