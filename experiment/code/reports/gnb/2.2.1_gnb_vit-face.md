# Klasifikasi DemogPairs Menggunakan Fitur ViT (Wajah) dengan Gaussian Naive Bayes

## 1. Konfigurasi Eksperimen

**Dataset — DemogPairs:**
- Sumber: `u.load_demogpairs()` — 10.800 citra (`[10800 rows x 5 columns]`), kolom `db_code`, `image_path`, `full_path`, `label`, `label_idx`.
- Database: `CWF`.
- Kelas (6): `Asian_Females`, `Asian_Males`, `Black_Females`, `Black_Males`, `White_Females`, `White_Males` — urutan evaluasi `target_names = u.demogpairs_classes` sesuai `classification_report`.
- Distribusi seimbang: tiap kelas ~1.800 total; pada `test` tiap kelas `support = 360` (2160 / 6).

**Fitur — ViT Wajah:**
- File: `features/demogpairs_vit-face.pkl` (`joblib.load`).
- Dimensi: `768` per gambar — output notebook: `Jumlah fitur per gambar: 768`.

**Split Data:**
```python
X = np.array([features[d['image_path']] for d in data])
y = np.array([d['label_idx'] for d in data])
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, stratify=y, random_state=42)
```
- Output: `(8640, 2160)` — Train 8.640 (80%), Test 2.160 (20%), `stratify=y`, `random_state=42`.

**Pipeline:**
```python
pipeline = Pipeline(steps=[('scaler', None), ('pca', None), ('classifier', None)])
```
- Urutan: `Scaler (opsional)` → `PCA (opsional)` → `GaussianNB`.

**Grid Pencarian Hyperparameter:**
```python
var_smoothing_values = np.logspace(-9, 2, 40)  # 40 nilai dari 1e-9 sampai 1e2
grid_params = [{
    'scaler': [None, MinMaxScaler()],
    'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],
    'classifier': [GaussianNB()],
    'classifier__var_smoothing': var_smoothing_values
}]
```
| Parameter | Opsi yang Diuji |
|---|---|
| `scaler` | `None`, `MinMaxScaler()` |
| `pca` | `None`, `PCA(n_components=0.5)`, `PCA(n_components=0.75)` |
| `classifier` | `GaussianNB()` |
| `classifier__var_smoothing` | 40 nilai `np.logspace(-9, 2, 40)` |

- Total kombinasi: **240** (2 × 3 × 40) — output: `GaussianNB: 240 kombinasi`.

**Cross-Validation & Scoring:**
```python
skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {'accuracy': 'accuracy', 'f1': 'f1_macro', 'precision': 'precision_macro', 'recall': 'recall_macro'}
GridSearchCV(estimator=pipeline, param_grid=params, cv=skv, refit='accuracy',
             scoring=scoring, n_jobs=int(joblib.cpu_count()*0.6), verbose=1,
             error_score='raise', return_train_score=True)
joblib.parallel_backend('threading')
```
- CV: `StratifiedKFold` 5-fold, `shuffle=True`, `random_state=42`.
- Scoring: `accuracy`, `f1_macro`, `precision_macro`, `recall_macro`; `refit='accuracy'`.
- Evaluasi: `u.evaluate_models(..., target_names=u.demogpairs_classes, model_prefix='models/clf_demogpairs_gnb_vit-face_', results_path='results/demogpairs_gnb_vit-face_')` — model tersimpan `models/clf_demogpairs_gnb_vit-face_GaussianNB.pkl`.
