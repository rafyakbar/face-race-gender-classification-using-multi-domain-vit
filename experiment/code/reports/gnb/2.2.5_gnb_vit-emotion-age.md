## 5. Hasil Cross-Validation

```python
var_smoothing_values = np.logspace(-9, 2, 40)  # dari 1e-9 sampai 1e2, 40 nilai

grid_params = [
    {
        'scaler': [None, MinMaxScaler()],
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],
        'classifier': [GaussianNB()],
        'classifier__var_smoothing': var_smoothing_values
    },
]
pipeline = Pipeline(steps=[
    ('scaler', None),
    ('pca', None),
    ('classifier', None)
])
skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy',
    'f1': 'f1_macro',
    'precision': 'precision_macro',
    'recall': 'recall_macro'
}
grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.6),
        verbose=1, error_score='raise',
        return_train_score=True
    )
    print(f'{key}: {len(ParameterGrid(params))} kombinasi')
```

**9. Key Observations**

1. **Best model:** GaussianNB dengan `var_smoothing=0.001603718743751331`, `MinMaxScaler` + `PCA` aktif — pipeline `MinMaxScaler → PCA → GaussianNB`. Accuracy test 76.81% dengan CV mean 75.54% (generalisasi positif +1.27 poin).
2. **Overall accuracy:** 76.81% pada test set (2,160 sampel; 360 per kelas) — di atas GNB ViT-Emotion (73.38%) dan GNB ViT-Age (69.63%) namun di bawah GNB ViT-Face (82.69%), menunjukkan fusi emosi+umur saling melengkapi namun belum menyamai fitur wajah murni untuk GNB.
3. **Kelas terbaik (F1):** Asian_Females (F1 0.7932, Precision tertinggi 0.8092, OvR Accuracy 0.9324) — paling mudah dipisahkan oleh distribusi Gaussian pada fitur emosi+umur.
4. **Kelas terlemah (F1):** Black_Females (F1 0.7293, Precision 0.7253, OvR 0.9093) — trade-off precision-recall terburuk, disusul White_Males (F1 0.7479).
5. **Recall tertinggi:** Black_Males (Recall 0.8139, F1 0.7855) meskipun precision moderat 0.7591 — model cenderung over-predict kelas ini (FP 36 ke Black_Females, 30 ke Asian_Females).
6. **Confusion patterns:**
   - Asian_Males paling sering salah ke White_Females (29) dan White_Males (24).
   - White_Males paling sering salah ke Asian_Males (34) dan Black_Females (29).
   - Black_Females tertukar ke Black_Males (32) dan White_Males (32).
   - Black_Males tertukar ke Black_Females (36).
   - Asian_Females tertukar ke Black_Males (30) dan White_Females (26).
   - White_Females tertukar ke White_Males (26) dan Asian_Males (21).
7. **Efek PCA + Scaler:** Semua top-4 kombinasi terbaik menggunakan `MinMaxScaler` + `PCA`; nilai var_smoothing optimal di orde 1e-09 hingga 1.6e-03 — smoothing kecil-menengah mempertahankan diskriminasi variansi. Tanpa scaler atau dengan smoothing sangat besar (27–100) akurasi kolaps ke ~53–54%.
8. **Efek var_smoothing:** Nilai sangat besar (≥ 27) tanpa scaler menempati rank terbawah (0.5368–0.5402) — smoothing berlebihan meratakan variansi Gaussian sehingga kelas tidak terpisahkan; Precision Mean tetap ~0.58 menunjukkan bias prediksi.
9. **Waktu pelatihan:** Grid search 240 kombinasi × 5 folds = 1,200 fits diselesaikan dalam 29m 48s wall-clock (parallel 60% CPU) atau 3h 1m 7s sekuensial — jauh lebih murah daripada SVM pada fitur serupa (jam–hari), namun lebih mahal daripada GNB single-feature (~38–40 menit sekuensial) karena dimensi ganda 1536.
10. **Gap CV vs Test kecil:** Best CV mean 0.7554 vs Test 0.7681 (selisih +0.0127) — tidak ada overfitting signifikan; pemilihan hyperparameter generalisasi dengan baik.
