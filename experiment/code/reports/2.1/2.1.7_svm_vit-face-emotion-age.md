# Klasifikasi DemogPairs Menggunakan Fitur ViT (Wajah, Emosi, dan Umur) & SVM

> **Notebook:** `2.1.7_svm_vit-face-emotion-age_demogpairs.ipynb`
> **Kernel:** Python 3 (ipykernel)

---

## 1. Ringkasan

Notebook ini melakukan klasifikasi dataset **DemogPairs** menggunakan fitur yang diekstrak dari tiga model ViT (Vision Transformer) — wajah, emosi, dan umur — yang digabungkan menjadi satu vektor fitur, kemudian diklasifikasikan menggunakan **Support Vector Machine (SVM)** dengan pencarian hyperparameter via **GridSearchCV** dan validasi silang **5-fold Stratified KFold**.

---

## 2. Dataset

Dataset **DemogPairs** terdiri dari **10.800 gambar** dengan 6 kelas demografis:

| Kelas | Label Index |
|---|---|
| Asian_Females | 5 |
| Asian_Males | — |
| Black_Females | — |
| Black_Males | — |
| White_Females | — |
| White_Males | 3 |

Dataset terbagi menjadi **train (8.640 sampel)** dan **test (2.160 sampel)** dengan rasio 80:20, stratified, `random_state=42`.

---

## 3. Fitur

Fitur diekstrak dari tiga model ViT dan digabungkan:

| Sumber | File |
|---|---|
| ViT Face | `features/demogpairs_vit-face.pkl` |
| ViT Emotion | `features/demogpairs_vit-emotion.pkl` |
| ViT Age | `features/demogpairs_vit-age.pkl` |

**Jumlah fitur per gambar: 2.304** (gabungan ketiga sumber)

---

## 4. Pipeline & Hyperparameter Search

### Pipeline
```
Scaler (opsional) → PCA (opsional) → SVM Classifier
```

### Hyperparameter Grid (288 kombinasi)

| Parameter | Nilai |
|---|---|
| Scaler | `None`, `MinMaxScaler()` |
| PCA | `None`, `PCA(n_components=0.5)`, `PCA(n_components=0.75)` |
| C | `0.01`, `0.1`, `1`, `10` |
| Kernel | `rbf`, `poly`, `linear` |
| Gamma | `scale`, `auto` |
| Degree | `2`, `3` |
| Tolerance | `1e-3` |
| Probability | `True` |

### Konfigurasi GridSearchCV
- **CV:** Stratified 5-fold (shuffle=True, random_state=42)
- **Refit:** accuracy
- **Scoring:** accuracy, f1_macro, precision_macro, recall_macro
- **n_jobs:** 60% dari jumlah CPU

## 11. Kesimpulan

- **Model terbaik:** SVM dengan kernel **polynomial** (`C=10`, `degree=2`, `gamma=scale`)
- **Akurasi test set: 93.70%** dengan precision, recall, dan F1 yang seimbang (~0.937)
- **Black_Males** mencapai performa tertinggi (F1=0.9614), sedangkan **White_Females** paling rendah (F1=0.9174)
- Fitur gabungan ViT (wajah + emosi + umur) menghasilkan representasi yang kuat untuk klasifikasi demografis
- Tanpa reduksi dimensi (PCA) dan tanpa scaling menghasilkan performa terbaik
