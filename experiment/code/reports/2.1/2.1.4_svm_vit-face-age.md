## 5. Kombinasi Parameter

```python
from sklearn.decomposition import PCA

grid_params = [
    {
        'scaler': [None, MinMaxScaler()],
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],
        
        'classifier': [SVC()],
        
        'classifier__C': [0.01, 0.1, 1, 10],
        'classifier__kernel': ['rbf', 'poly', 'linear'],
        
        'classifier__gamma': ['scale', 'auto'],
        'classifier__degree': [2, 3],
        
        'classifier__tol': [1e-3],
        'classifier__probability': [True],
    },
]

pipeline = Pipeline(steps=[
    ('scaler', None),
    ('pca', None),
    ('classifier', None)
])

skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy', 
    'f1': 'f1_macro', 
    'precision': 'precision_macro', 
    'recall': 'recall_macro'
}

grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.6),
        verbose=1, error_score='raise',
        return_train_score=True
    )
    print(f'{key}: {len(ParameterGrid(params))} kombinasi')
```

## 10. Key Observations

- **Best model:** SVM (SVC) with C=10, poly kernel, degree=2, scale gamma, no PCA, no scaling achieves **92.55% test accuracy**.
- **Class imbalance not an issue:** All 6 classes have exactly 360 test samples (balanced dataset).
- **Strongest class:** Black_Males (F1=0.9488, OvR Accuracy=98.29%).
- **Weakest class:** White_Females (F1=0.9045, OvR Accuracy=96.85%).
- **PCA + MinMaxScaler hurts performance dramatically:** Configurations with PCA=PCA and scaler=MinMaxScaler with poly kernel drop accuracy to ~55–58%, a ~37 percentage point decrease from the best.
- **Kernel matters:** Poly kernel (degree=2, C=10) outperforms rbf (degree=2/3, C=10) and linear kernels.
- **Total training time:** 2 days 2 hours 11 minutes 24 seconds (288 combinations × 5 folds + refit).
- **Job training time:** 6 hours 9 minutes 57 seconds.
- **Grid search explored 288 total parameter combinations.**
- **Combining ViT-Face and ViT-Age features** (1,536 dims) improves over ViT-Face alone (90.83% → 92.55%), a **+1.72%** accuracy gain.
