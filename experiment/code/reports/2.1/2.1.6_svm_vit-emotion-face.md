# Klasifikasi DemogPairs Menggunakan ViT (Emosi dan Wajah) & SVM

**Notebook:** `2.1.6_svm_vit-emotion-face_demogpairs.ipynb`

---

## 1. Ringkasan Pendekatan

Pipeline klasifikasi menggunakan fitur gabungan dari dua model ViT (ViT-Face dan ViT-Emotion) yang diekstrak dari dataset DemogPairs, kemudian diklasifikasikan menggunakan Support Vector Machine (SVC) dengan grid search dan 5-fold stratified cross-validation.

**Kelas target (6 kelas demografis):** `Asian_Females`, `Asian_Males`, `Black_Females`, `Black_Males`, `White_Females`, `White_Males`

| Set | Jumlah Sampel |

- Proporsi kelas dipertahankan di train dan test.

---

## 5. Hyperparameter Grid Search

- **Classifier:** SVC (Support Vector Classifier)
- **Pipeline:** Scaler (opsional) → PCA (opsional) → SVC
- **Cross-validation:** 5-Fold Stratified K-Fold (`random_state=42`)
- **Scoring:** Accuracy, F1 (macro), Precision (macro), Recall (macro)

**Parameter yang ditelusuri:**

| Parameter | Nilai |
|---|---|
| `C` | 0.01, 0.1, 1, 10 |
| `kernel` | rbf, poly, linear |
| `gamma` | scale, auto |
| `degree` | 2, 3 |
| `scaler` | None, MinMaxScaler() |
| `pca` | None, PCA(0.5), PCA(0.75) |
| `tol` | 1e-3 |
| `probability` | True |

**Total kombinasi parameter:** 288

## 10. Observasi & Kesimpulan

1. **Performa keseluruhan sangat baik:** Akurasi 93.29% pada 6 kelas demografis dengan fitur gabungan ViT-Emotion + ViT-Face.
2. **Kelas dengan performa terbaik:** Black_Males (F1=0.9587) dan Asian_Females (F1=0.9560).
3. **Kelas dengan performa terendah:** White_Males (F1=0.9073) dan White_Females (F1=0.9257).
4. **Confusion terbesar:** White_Males sering diklasifikasikan sebagai Asian_Males (17 kasus), menunjukkan tantungan dalam membedakan karakteristik wajah antara kedua kelas tersebut.
5. **Best configuration:** SVC dengan C=10, kernel=rbf, gamma=scale, MinMaxScaler, tanpa PCA.
6. **PCA menurunkan performa:** Konfigurasi dengan PCA menghasilkan akurasi CV lebih rendah (~0.71–0.90) dibandingkan tanpa PCA.
7. **Scaling bermanfaat:** MinMaxScaler konsisten muncul di konfigurasi terbaik.
8. **Waktu komputasi:** Total pelatihan ~2 hari 2 jam untuk 288 kombinasi × 5 fold CV.
