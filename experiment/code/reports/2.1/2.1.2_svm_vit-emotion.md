# Klasifikasi DemogPairs Menggunakan ViT (Emosi) & SVM

Laporan ini mempresentasikan hasil eksperimen klasifikasi demografi (DemogPairs) menggunakan fitur ekstraksi dari model ViT (Emosi) yang diklasifikasikan dengan Support Vector Machine (SVM). Dataset DemogPairs terdiri dari 10.800 gambar dengan 6 kelas demografis: Asian_Females, Asian_Males, Black_Females, Black_Males, White_Females, dan White_Males. Setiap gambar diekstrak fiturnya menggunakan ViT (Emosi) menghasilkan vektor berdimensi 768. Model SVM dilatih dengan grid search untuk mencari kombinasi parameter terbaik.

---

## Konfigurasi Eksperimen

| Komponen | Nilai |
|---|---|
| Dataset | DemogPairs (10.800 gambar) |
| Jumlah Kelas | 6 (Asian_Females, Asian_Males, Black_Females, Black_Males, White_Females, White_Males) |
| Fitur | ViT (Emosi) — 768 dimensi per gambar |
| Classifier | Support Vector Machine (SVC) |
| Train/Test Split | 8.640 / 2.160 (80%/20%, stratified, random_state=42) |
| Cross-Validation | StratifiedKFold, 5 folds, shuffle=True, random_state=42 |
| Scoring | Accuracy (refit), F1-macro, Precision-macro, Recall-macro |
| Jumlah Kombinasi Parameter | 288 |
| Parameter Grid | |
| — C | 0.01, 0.1, 1, 10 |
| — kernel | rbf, poly, linear |
| — gamma | scale, auto |
| — degree | 2, 3 |
| — scaler | None, MinMaxScaler |
| — pca | None, PCA(0.5), PCA(0.75) |
| — tol | 1e-3 |
| — probability | True |
