# Klasifikasi DemogPairs Menggunakan Fitur ViT (Umur) & SVM

## Ringkasan Eksperimen

| Item | Detail |
|------|--------|
| **Notebook** | `2.1.3_svm_vit-age_demogpairs.ipynb` |
| **Dataset** | DemogPairs |
| **Jumlah Sampel** | 10.800 |
| **Jumlah Kelas** | 6 |
| **Kelas** | Asian_Females, Asian_Males, Black_Females, Black_Males, White_Females, White_Males |
| **Fitur** | ViT (Umur) — 768 dimensi per gambar |
| **Klasifier** | Support Vector Machine (SVC) |
| **Kernel (terbaik)** | rbf |
| **C (terbaik)** | 10 |
| **gamma (terbaik)** | scale |
| **degree (terbaik)** | 2 |
| **Scaling** | None (tidak ada scaling) |
| **Reduksi Dimensi** | None (tidak ada PCA) |
| **Train / Test Split** | 8.640 / 2.160 (80/20, stratified, random_state=42) |
| **Cross-Validation** | StratifiedKFold, 5 fold |

## Pipeline

```
None → None → SVC(C=10, kernel='rbf', gamma='scale', degree=2, probability=True, tol=0.001)
```

- `classifier__C`: 0.01, 0.1, 1, 10
- `classifier__kernel`: rbf, poly, linear
- `classifier__gamma`: scale, auto

- `classifier__tol`: 0.001
- `classifier__probability`: True

## Catatan

- Model file tersimpan di: `models/clf_demogpairs_svm_vit-age_SVC.pkl`
- Results file tersimpan di: `results/demogpairs_svm_vit-age_`
- Fitur ViT (Umur) berdimensi 768, digunakan tanpa reduksi dimensi (PCA) dan tanpa scaling pada konfigurasi terbaik.
- Konfigurasi terbaik: SVC dengan kernel RBF, C=10, gamma=scale, tanpa PCA, tanpa scaler.
- Black_Males memiliki performa terbaik (F1=0.9188, OvR Accuracy=0.9731).
- White_Females memiliki performa terendah (F1=0.8303, OvR Accuracy=0.9431), menunjukkan kesulitan model dalam mengenali kelas ini.
- Akurasi fold terbaik pada CV: 0.8678 (C=10, rbf, pca=None, scaler=None).
- Akurasi fold terburuk pada CV: 0.3209 (C=0.01, poly, pca=PCA, scaler=MinMaxScaler).
