# Klasifikasi DemogPairs Menggunakan Fitur ViT (Emosi dan Umur) & SVM

> **Notebook:** `2.1.5_svm_vit-emotion-age_demogpairs.ipynb`

---

## 1. Ringkasan

Notebook ini melakukan klasifikasi dataset **DemogPairs** menggunakan fitur yang diekstrak dari dua model ViT (Vision Transformer) — emosi dan umur — yang digabungkan menjadi satu vektor fitur, kemudian diklasifikasikan menggunakan **Support Vector Machine (SVM)** dengan pencarian hyperparameter via **GridSearchCV** dan validasi silang **5-fold Stratified KFold**.

---

## 2. Dataset

Dataset **DemogPairs** terdiri dari **10.800 gambar** dengan 6 kelas demografis:

| Kelas | Label Index |
|---|---|
| Asian_Females | 5 |
| Asian_Males | — |
| Black_Females | — |
| Black_Males | — |
| White_Females | — |
| White_Males | 3 |

Dataset terbagi menjadi **train (8.640 sampel)** dan **test (2.160 sampel)** dengan rasio 80:20, stratified, `random_state=42`.

---

## 3. Fitur

Fitur diekstrak dari dua model ViT dan digabungkan:

| Sumber | File |
|---|---|
| ViT Emotion | `features/demogpairs_vit-emotion.pkl` |
| ViT Age | `features/demogpairs_vit-age.pkl` |

**Jumlah fitur per gambar: 1.536** (gabungan kedua sumber)

---

## 4. Pipeline & Hyperparameter Search

### Pipeline
```
Scaler (opsional) → PCA (opsional) → SVM Classifier
```

### Hyperparameter Grid

| Parameter | Nilai |
|---|---|
| Scaler | `None`, `MinMaxScaler()` |
| PCA | `None`, `PCA(n_components=0.5)`, `PCA(n_components=0.75)` |
| C (regularisasi) | 0.01, 0.1, 1, 10 |
| Kernel | `rbf`, `poly`, `linear` |
| Gamma | `scale`, `auto` |
| Degree | 2, 3 |
| Tolerance | 1e-3 |
| Probability | True |

**Total kombinasi: 288**

### Cross-Validation
```python
StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
```

**Scoring:** Accuracy, F1 (macro), Precision (macro), Recall (macro)
