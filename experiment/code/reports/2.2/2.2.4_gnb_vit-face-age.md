# Klasifikasi DemogPairs Menggunakan ViT (Wajah dan Umur) & Gaussian Naive Bayes

Laporan eksperimen klasifikasi DemogPairs menggunakan fitur ViT embedding 1536 dimensi (Wajah + Umur) dengan Gaussian Naive Bayes (GNB). Dataset terdiri dari 6 kelas demografi (Asian_Females, Asian_Males, Black_Females, Black_Males, White_Females, White_Males). Dilakukan grid search terhadap kombinasi parameter var_smoothing, scaler, dan PCA untuk menemukan konfigurasi terbaik.

## 1. Konfigurasi Eksperimen

- **Fitur**: ViT embedding 768 dimensi (Wajah) + 768 dimensi (Umur) = 1536 dimensi per gambar
- **Dataset**: DemogPairs (10.800 gambar, 6 kelas)
- **Split**: 80/20 (8640 train / 2160 test)
- **Classifier**: Gaussian Naive Bayes
- **Parameter Grid**: var_smoothing (40 nilai logspace 1e-9 hingga 1e2), scaler (None, MinMaxScaler), PCA (None, 0.5, 0.75)
- **Kombinasi Parameter**: 240 (40 var_smoothing × 2 scaler × 3 PCA)
- **Cross-Validation**: StratifiedKFold, 5 fold
