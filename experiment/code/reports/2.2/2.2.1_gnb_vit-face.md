# Klasifikasi DemogPairs Menggunakan ViT (Wajah) & Gaussian Naive Bayes

## Ringkasan Eksperimen

| Item | Detail |
|------|--------|
| **Notebook** | `2.2.1_gnb_vit-face_demogpairs.ipynb` |
| **Dataset** | DemogPairs |
| **Jumlah Sampel** | 10.800 |
| **Jumlah Kelas** | 6 |
| **Kelas** | Asian_Females, Asian_Males, Black_Females, Black_Males, White_Females, White_Males |
| **Fitur** | ViT (Wajah) — 768 dimensi per gambar |
| **Klasifier** | Gaussian Naive Bayes |
| **Scaling** | MinMaxScaler |
| **Reduksi Dimensi** | PCA (n_components=0.5) |
| **var_smoothing (terbaik)** | 0.04124626382901348 |
| **Train / Test Split** | 8.640 / 2.160 (80/20, stratified, random_state=42) |
| **Cross-Validation** | StratifiedKFold, 5 fold |

---

## Pipeline

```
MinMaxScaler → PCA(n_components=0.5) → GaussianNB(var_smoothing=0.0412)
```

**Parameter Grid (240 kombinasi):**
- `scaler`: None, MinMaxScaler
- `pca`: None, PCA(0.5), PCA(0.75)
- `classifier__var_smoothing`: 40 nilai (logspace dari 1e-9 hingga 1e2)

## Catatan

- Model file tersimpan di: `models/clf_demogpairs_gnb_vit-face_GaussianNB.pkl`
- Results file tersimpan di: `results/demogpairs_gnb_vit-face_`
- Fitur ViT (Wajah) berdimensi 768, direduksi ke 50% (384 dimensi) menggunakan PCA sebelum klasifikasi.
- Kelas White_Females memiliki recall terendah (0.6972), menunjukkan kesulitan model dalam mengenali kelas ini.
- Asian_Males memiliki performa terbaik (F1=0.8867).
