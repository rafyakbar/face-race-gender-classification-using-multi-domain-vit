# Klasifikasi DemogPairs Menggunakan ViT (Emosi dan Wajah) & Gaussian Naive Bayes

## Ringkasan Eksperimen

| Item | Detail |
|------|--------|
| **Notebook** | `2.2.6_gnb_vit-emotion-face_demogpairs.ipynb` |
| **Dataset** | DemogPairs |
| **Jumlah Sampel** | 10.800 |
| **Jumlah Kelas** | 6 |
| **Kelas** | Asian_Females, Asian_Males, Black_Females, Black_Males, White_Females, White_Males |
| **Fitur** | ViT (Emosi) + ViT (Wajah) — 1.536 dimensi per gambar (768 + 768) |
| **Klasifier** | Gaussian Naive Bayes |
| **Scaling** | MinMaxScaler |
| **Reduksi Dimensi** | PCA (n_components=0.75) |
| **var_smoothing (terbaik)** | 0.0058780160722749115 |
| **Train / Test Split** | 8.640 / 2.160 (80/20, stratified, random_state=42) |
| **Cross-Validation** | StratifiedKFold, 5 fold |


## Catatan

- Model file tersimpan di: `models/clf_demogpairs_gnb_vit-emotion-face_GaussianNB.pkl`
- Results file tersimpan di: `results/demogpairs_gnb_vit-emotion-face_`
- Fitur ViT (Emosi) dan ViT (Wajah) masing-masing berdimensi 768, digabungkan menjadi 1.536 dimensi per gambar.
- PCA n_components=0.75 direduksi dari 1.536 dimensi.
- Kelas White_Males memiliki recall terendah (0.8194), menunjukkan kesulitan model dalam mengenali kelas ini dibanding kelas lain.
- Black_Males memiliki performa terbaik berdasarkan recall (0.9222) dan F1-score (0.8877).
- Nilai var_smoothing terbaik (0.00588) lebih kecil dibanding model ViT-Face saja (0.0412), menunjukkan kombinasi fitur emosi+wajah membutuhkan smoothing yang lebih rendah.
- Akurasi keseluruhan (0.8486) lebih tinggi dibanding model ViT-Face saja (0.8269), menunjukkan penambahan fitur emosi meningkatkan performa klasifikasi.
