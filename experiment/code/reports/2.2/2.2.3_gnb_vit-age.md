### Pipeline Steps

1. **Scaler** — `None` or `MinMaxScaler`
2. **PCA** — `None`, `PCA(n_components=0.5)`, or `PCA(n_components=0.75)`
3. **Classifier** — `GaussianNB`

### Hyperparameter Grid

- **`var_smoothing`**: 40 values from `1e-9` to `1e2` (log-spaced via `np.logspace(-9, 2, 40)`)
- **Total combinations**: 2 × 3 × 40 = **240**

### Cross-Validation

- **Method**: 5-Fold Stratified K-Fold (`random_state=42`)
- **Scoring metrics**: Accuracy, F1 Macro, Precision Macro, Recall Macro
- **Refit criterion**: Accuracy

## 8. Summary

This experiment applies a **Gaussian Naive Bayes** classifier to DemogPairs dataset using **ViT (Vision Transformer) age-based features** (768-dimensional embeddings). Key findings:

- **Test accuracy: 69.63%** — moderate performance for a simple probabilistic classifier
- **Best configuration**: MinMaxScaler + PCA (75% variance) + GaussianNB with `var_smoothing ≈ 4.38e-4`
- **Males consistently outperform Females** in recall across all races (Asian Males 75.0% vs Asian Females 70.0%; Black Males 77.8% vs Black Females 60.6%; White Males 71.4% vs White Females 63.1%)
- **Black_Females is the hardest class** to classify (F1: 0.6459), suggesting the ViT age features may not adequately capture this demographic's characteristics
- **Black_Males is the easiest class** (F1: 0.7359), achieving the highest recall among all classes
- The model benefits from dimensionality reduction (PCA) and feature scaling (MinMaxScaler), indicating the raw ViT features have heterogeneous scales
