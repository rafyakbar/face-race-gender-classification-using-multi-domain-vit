# 2.5.4 — Logistic Regression with ViT (Face + Age) on DemogPairs

> **Notebook:** `2.5.4_lr_vit-face-age_demogpairs.ipynb`
> **Kernel:** Python 3 (ipykernel)
> **Classification:** 6-class DemogPairs (race × gender)

---

## 1. Overview

This notebook evaluates a **Logistic Regression** classifier using concatenated ViT features from two models — a **face** ViT and an **age** ViT — on the DemogPairs dataset. It performs a grid search over preprocessing and regularization hyperparameters with 5-fold stratified cross-validation, then reports test-set performance.

## 10. Key Observations

1. **Best configuration:** `LogisticRegression(C=0.1, solver=newton-cg, max_iter=500)` with no scaling and no PCA — raw concatenated ViT features work best.
2. **Overall accuracy: 91.62%** — strong performance for a linear classifier on 1,536-dim ViT features across 6 demographic groups.
3. **Best-performing class:** Black_Males (F1=0.9436, OvR accuracy=0.9810) — highest recall at 0.9528.
4. **Worst-performing class:** White_Females (F1=0.8982, OvR accuracy=0.9662) — lowest recall at 0.8944.
5. **PCA hurts performance:** Configurations with PCA dropped from ~91.5% to ~86.4% mean CV accuracy, suggesting the full feature space is informative.
6. **Scaling is unnecessary:** The best model uses no scaler, indicating the ViT features are already well-scaled.
7. **Solver/newton-cg converges fastest** for this feature dimensionality — the top 3 configurations all use newton-cg with varying max_iter (500, 1000, 2000), all converging to the same accuracy.
