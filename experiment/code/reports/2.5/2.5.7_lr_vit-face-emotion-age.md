# 2.5.7 — Klasifikasi DemogPairs Menggunakan ViT (Wajah, Emosi, dan Umur) & Logistic Regression

> **Notebook:** `2.5.7_lr_vit-face-emotion-age_demogpairs.ipynb`
> **Task:** Multi-class classification of demographic pairs (race × gender) using concatenated ViT features (face + emotion + age) with Logistic Regression.

---

## 1. Dataset

- **Dataset:** DemogPairs
- **Total samples:** 10,800 images
- **Classes (6):** `Asian_Females`, `Asian_Males`, `Black_Females`, `Black_Males`, `White_Females`, `White_Males`
- **Class distribution:** Balanced — 1,800 samples per class (each class appears 1,800 times)
- **Sample data columns:** `db_code`, `image_path`, `full_path`, `label`, `label_idx`

## 2. Feature Extraction

Three ViT model feature sets were loaded and concatenated per image:

| Feature Source | File |
|----------------|------|
| ViT-Face       | `features/demogpairs_vit-face.pkl` |
| ViT-Emotion    | `features/demogpairs_vit-emotion.pkl` |
| ViT-Age        | `features/demogpairs_vit-age.pkl` |

- **Total features per image:** 2,304
- **Feature concatenation:** Face features + Emotion features + Age features
- **Progress:** 10,800/10,800 processed in ~1.5 seconds (7,195.19 it/s)

---

## 3. Data Split

- **Method:** Stratified train-test split (`stratify=y`, `random_state=42`)
- **Test size:** 20%
- **Training set:** 8,640 samples
- **Test set:** 2,160 samples

## 4. Hyperparameter Search

### Pipeline

```
Pipeline(steps=[
    ('scaler', None | MinMaxScaler()),
    ('pca', None | PCA(n_components=0.5) | PCA(n_components=0.75)),

])
```

### Grid Parameters

| Parameter | Values |

- **Refit criterion:** Accuracy

### Key Observations

- **Best CV accuracy:** 0.9219 (top configs), **Test accuracy:** 0.9273
- **No PCA/Scaler is optimal:** The best configurations all use `pca=None` and `scaler=None`, indicating the raw concatenated ViT features are well-suited without dimensionality reduction or normalization
- **C=0.1 dominates:** The top 4 configurations all use `C=0.1`, suggesting moderate regularization is optimal
- **Solver matters for speed:** `newton-cg` and `lbfgs` are much faster than `saga` for similar accuracy
- **Bottom configs use PCA:** Configurations with PCA reduction (n_components=0.5) drop accuracy to ~0.874
