## 5. Kombinasi Parameter (Grid Search Configuration)

```python
grid_params = [
    {
        'scaler': [None, MinMaxScaler()],
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],
        
        'classifier': [RandomForestClassifier(random_state=42)],
        'classifier__n_estimators': [100, 200],
        'classifier__max_depth': [None, 20, 30],
        'classifier__min_samples_split': [2, 5],
        'classifier__min_samples_leaf': [1, 2],
        'classifier__max_features': ['sqrt', 'log2'],
    },
]

pipeline = Pipeline(steps=[
    ('scaler', None),
    ('pca', None),
    ('classifier', None)
])

skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy', 
    'f1': 'f1_macro', 
    'precision': 'precision_macro', 
    'recall': 'recall_macro',
}

grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.6),
        verbose=1, error_score='raise',
        return_train_score=True
    )
    print(f'{key}: {len(ParameterGrid(params))} kombinasi')
```

## 9. Key Observations

1. **Best model:** RandomForest dengan n_estimators=200, max_depth=30, max_features=log2, min_samples_split=2, min_samples_leaf=1, PCA aktif, tanpa scaler — accuracy 73.66% pada test set (2,160 sampel).
2. **Overall accuracy:** 73.66% — jauh di atas peluang acak 16.67% untuk 6 kelas, namun deutlich lebih rendah daripada varian RF dengan fitur face (biasanya >80%) dan SVM dengan vit-age (87.64%).
3. **Kelas terkuat:** Black_Males (F1: 0.7800, recall: 0.8028, OvR accuracy: 0.9245) dan Asian_Females (F1: 0.7810, recall: 0.7972) — model paling mampu mengenali kedua kelas ini.
4. **Kelas terlemah:** Black_Females (F1: 0.6786, recall: 0.6333, precision: 0.7308) — 132 dari 360 sampel salah klasifikasi, terutama sebagai Asian_Females (41) dan White_Males (41).
5. **Pola kesalahan (confusion patterns):**
   - Asian_Males sering salah sebagai White_Males (42) dan White_Females (34).
   - Black_Females↔Asian_Females (41) dan Black_Females↔White_Males (41) menunjukkan batas fenotipe usia yang ambigu.
   - White_Females sering salah sebagai Asian_Males (41) dan Asian_Females (30).
   - White_Males salah sebagai Asian_Males (28) dan White_Females (27).
6. **PCA membantu:** 4 konfigurasi teratas semuanya menggunakan PCA, berbeda dari eksperimen SVM di mana PCA justru menurunkan performa. Pada RF, reduksi dimensi ViT-Age 768 → komponen PCA signifikan meningkatkan generalisasi.
7. **Tanpa scaler lebih baik:** Best model menggunakan `scaler=None`; semua top-4 juga tanpa scaler. MinMaxScaler muncul hanya di bottom-4.
8. **max_features=log2 dominan:** Seluruh top-4 dan bottom-4 menggunakan `log2`; `sqrt` tidak masuk ekstrem — mengindikasikan `log2` lebih stabil pada data ini.
9. **n_estimators=200 vs 100:** Top-4 menggunakan 200 trees (≈10s per fold), bottom-4 menggunakan 100 trees (≈5–6s per fold) — lebih banyak trees meningkatkan accuracy ~9%.
10. **Training cost:** Grid search memerlukan ~1 jam wall-clock paralel (3,868s) atau ~4 jam sekuensial (14,876s) untuk 288 kombinasi × 5 CV folds — jauh lebih ringan daripada SVM vit-age (35 jam sekuensial).
