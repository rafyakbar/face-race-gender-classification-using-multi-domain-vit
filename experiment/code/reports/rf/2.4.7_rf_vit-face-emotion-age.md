# 2.4.7 — Random Forest dengan ViT (Wajah, Emosi, dan Umur) Tri-Domain pada DemogPairs

> **Notebook:** `2.4.7_rf_vit-face-emotion-age_demogpairs.ipynb` — Klasifikasi DemogPairs Menggunakan ViT (Wajah, Emosi, dan Umur) & Random Forest
> **Fitur:** Tri-domain 2304 dimensi (ViT-Face 768 + ViT-Emotion 768 + ViT-Age 768)
> **Dataset:** DemogPairs 10.800 gambar, 6 kelas demografis (Asian_Females, Asian_Males, Black_Females, Black_Males, White_Females, White_Males)
> **Model:** Random Forest — GridSearchCV 288 kombinasi, Stratified 5-Fold
> **Sumber data:** Diekstrak langsung dari output cell notebook (tanpa mengarang)

Eksperimen ini mengevaluasi **Random Forest** pada fitur gabungan **ViT wajah + emosi + umur** (tri-domain) untuk klasifikasi 6 pasangan ras-gender pada DemogPairs. Seluruh nilai pada laporan ini diambil verbatim dari output notebook.

```python
face_features = joblib.load('features/demogpairs_vit-face.pkl')
emotion_features = joblib.load('features/demogpairs_vit-emotion.pkl')

for d in tqdm(data):
    key = d['image_path']

print('Jumlah fitur per gambar:', np.array(features[list(features.keys())[0]]).shape[0])
```

### 1.6 Cross-Validation & Scoring

```python
skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

    'accuracy': 'accuracy',

grid_models[key] = GridSearchCV(
```

### 5.4 Interpretasi CV

- **Konsistensi:** Selisih antar fold pada konfigurasi terbaik hanya 0.0237 (0.8860–0.8623), menandakan model stabil lintas split.
- **Efek PCA:** Semua top-4 menggunakan `pca=PCA`; bottom 2 tanpa PCA, mengindikasikan reduksi dimensi membantu pada 2304-D.
- **Efek scaler:** `scaler=None` mendominasi top-2; `MinMaxScaler` tidak merugikan banyak (top-3/4 masih 0.873+).
- **Efek max_features:** `sqrt` mengungguli `log2` pada setting terbaik (log2 mendominasi bottom).
