## 5. Kombinasi Parameter (Grid Search Configuration)

```python
grid_params = [
    {
        'scaler': [None, MinMaxScaler()],
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],
        'classifier': [RandomForestClassifier(random_state=42)],
        'classifier__n_estimators': [100, 200],
        'classifier__max_depth': [None, 20, 30],
        'classifier__min_samples_split': [2, 5],
        'classifier__min_samples_leaf': [1, 2],
        'classifier__max_features': ['sqrt', 'log2'],
    },
]

pipeline = Pipeline(steps=[
    ('scaler', None),
    ('pca', None),
    ('classifier', None)
])

skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy',
    'f1': 'f1_macro',
    'precision': 'precision_macro',
    'recall': 'recall_macro'
}

grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.6),
        verbose=1, error_score='raise',
        return_train_score=True
    )
    print(f'{key}: {len(ParameterGrid(params))} kombinasi')
```

## 9. Key Observations

1. **Best model:** RandomForest dengan n_estimators=200, max_depth=None, max_features=log2, min_samples_split=5, min_samples_leaf=1, pca=PCA, scaler=None — accuracy 80.60% pada test set (2,160 sampel).
2. **Overall accuracy:** 80.60% dengan macro F1 80.57%. Lebih rendah dibanding SVM pada fitur yang sama (~90%), menunjukkan ViT-emotion kurang discriminative untuk RF dibanding SVM.
3. **Best-performing class:** Asian_Females (F1: 0.8745, OvR Accuracy: 95.88%, Precision: 0.8883).
4. **Worst-performing class:** White_Males (F1: 0.7486, Recall: 0.7278, OvR Accuracy: 91.85%) — sering tertukar dengan Black_Females (38 salah klasifikasi) dan Asian_Males (37 salah klasifikasi).
5. **Black_Females** juga lemah (F1: 0.7590), sering tertukar dengan Black_Males (36 salah klasifikasi).
6. **PCA membantu:** Semua kombinasi top 4 menggunakan PCA, menunjukkan reduksi dimensi bermanfaat pada ruang fitur 768-dim untuk RF.
7. **n_estimators 200 > 100:** Kombinasi terbaik semua menggunakan 200 trees, bottom 4 semua menggunakan 100 trees.
8. **Tanpa PCA performa terendah:** Bottom 4 semua memiliki pca=None, mengindikasikan raw 768-dim kurang optimal untuk RF tanpa reduksi.
9. **Training cost:** Grid search memerlukan ~1 jam wall-clock (parallel, 60% CPU) atau ~4 jam sequential equivalent untuk 288 kombinasi × 5 CV folds.
10. **Confusion patterns:** White classes saling tertukar (White_Males → White_Females 16, White_Females → White_Males 24) dan cross-race gender confusions lebih dominan.
