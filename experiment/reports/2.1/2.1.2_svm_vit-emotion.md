## 5. Kombinasi Parameter (Grid Search Configuration)

```python
from sklearn.decomposition import PCA

grid_params = [
    {
        'scaler': [None, MinMaxScaler()],
        'pca': [None, PCA(n_components=0.5), PCA(n_components=0.75)],
        'classifier': [SVC()],
        'classifier__C': [0.01, 0.1, 1, 10],
        'classifier__kernel': ['rbf', 'poly', 'linear'],
        'classifier__gamma': ['scale', 'auto'],
        'classifier__degree': [2, 3],
        'classifier__tol': [1e-3],
        'classifier__probability': [True],
    },
]

pipeline = Pipeline(steps=[
    ('scaler', None),
    ('pca', None),
    ('classifier', None)
])

skv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = {
    'accuracy': 'accuracy',
    'f1': 'f1_macro',
    'precision': 'precision_macro',
    'recall': 'recall_macro'
}

grid_models = {}
for params in grid_params:
    key = str(params['classifier'][0]).split('(')[0]
    grid_models[key] = GridSearchCV(
        estimator=pipeline,
        param_grid=params,
        cv=skv, refit='accuracy',
        scoring=scoring, n_jobs=int(joblib.cpu_count() * 0.6),
        verbose=1, error_score='raise',
        return_train_score=True
    )
    print(f'{key}: {len(ParameterGrid(params))} kombinasi')
```

## 9. Key Observations

1. **Best model:** SVC with C=10, kernel=rbf, gamma=scale — no scaling, no PCA applied.
2. **Overall accuracy:** 90.19% on the test set (2,160 samples).
3. **Class balance:** All 6 demographic pairs are evenly represented (360 test samples each).
4. **Best-performing class:** Asian_Females (F1: 0.9366, OvR Accuracy: 97.87%).
5. **Worst-performing class:** White_Males (F1: 0.8708, OvR Accuracy: 95.74%).
6. **Confusion patterns:** Cross-race confusions (e.g., Black_Males ↔ Black_Females, White_Males ↔ White_Females) are more common than within-race confusions.
7. **PCA hurts performance:** Combinations with PCA consistently underperform those without PCA, especially at lower C values.
8. **Poly kernel collapses:** Low C + poly kernel + PCA yields ~29% accuracy, near random guessing for 6 classes.
9. **Scaling (MinMaxScaler) provides marginal benefit** on rbf kernel at C=10, nearly matching no-scaling performance.
10. **Training cost:** Grid search required ~4 hours wall-clock (parallel) or ~32 hours sequential equivalent for 288 parameter combinations × 5 CV folds.
