Model ensemble RF mengagregasikan prediksi sekumpulan pohon keputusan independen untuk mengklasifikasikan fitur wajah berdasarkan prinsip bootstrap aggregating (bagging) dan random subspace method \cite{ref30}. Pendekatan ini mereduksi varians prediksi dengan membangun sebanyak $B$ pohon klasifikasi dari sampel acak data latih \cite{ref31}. Setiap percabangan node membatasi pemilihan fitur pada subset acak berukuran max\_features $\in \{\text{'sqrt'}, \text{'log2'}\}$ untuk menekan korelasi antarpohon \cite{ref32}. Kriteria pemisahan cabang mengoptimalkan indeks Gini impurity hingga memenuhi ambang batas minimum pemisahan node min\_samples\_split, batas kedalaman max\_depth, atau batas minimum daun min\_samples\_leaf \cite{ref33}. Mekanisme majority voting menentukan keputusan akhir sampel citra melintasi seluruh pohon keputusan \cite{ref34}. Prosedur penalaan hyperparameter mengevaluasi kombinasi penskalaan fitur, reduksi dimensionalitas PCA, variasi jumlah pohon n\_estimators, serta batasan pertumbuhan pohon, menghasilkan 288 konfigurasi grid dengan 1,440 total fits melalui 5-Fold Stratified Cross-Validation sebagaimana dirangkum pada Table~\ref{tab:III}.
