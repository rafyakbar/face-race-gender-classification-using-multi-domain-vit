The RF ensemble aggregates predictions from independent decision trees to classify facial features using bootstrap aggregating (bagging) and random subspaces \cite{ref30}. This approach reduces prediction variance by constructing $B$ classification trees from random samples of the training data \cite{ref31}. Each node split restricts feature selection to a random subset of size max\_features $\in \{\text{'sqrt'}, \text{'log2'}\}$ to suppress inter-tree correlation \cite{ref32}. The split criterion optimizes the Gini impurity index until satisfying the minimum node split threshold min\_samples\_split, the maximum depth limit max\_depth, or the minimum leaf threshold min\_samples\_leaf \cite{ref33}. The majority voting mechanism determines the final decision for an image sample across all decision trees \cite{ref34}. Hyperparameter tuning evaluates feature scaling, PCA dimensionality reduction, tree counts n\_estimators, and tree growth constraints, producing 288 grid configurations with 1,440 total fits via 5-Fold Stratified Cross-Validation in Table~\ref{tab:III}.
