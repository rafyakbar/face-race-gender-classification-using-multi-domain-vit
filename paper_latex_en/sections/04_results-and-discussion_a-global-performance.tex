Performance evaluation of RF across seven feature configurations on the DemogPairs test data is presented in Table~\ref{tab:VII}. Experimental results demonstrate that the dual-domain Emotion $\oplus$ Face scheme achieves peak performance, recording an Accuracy of 86.85\% and an F1-Score of 86.82\%. In contrast, tri-domain Face $\oplus$ Emotion $\oplus$ Age exhibits slight degradation to an Accuracy of 86.20\% and an F1-Score of 86.13\%, reflecting challenges in partitioning 2,304 dimensions via random tree splits \cite{ref48}. All GridSearchCV configurations select PCA 0.75 dimensionality reduction to balance data variance. In the single-domain category, Face achieves the best performance with an Accuracy of 85.46\%, surpassing Emotion at 80.60\% and Age at 73.66\%.

The performance evaluation of probabilistic GNB classification across seven feature configurations is summarized in Table~\ref{tab:VIII}. The GNB model demonstrates a consistent performance improvement from single-domain to multi-domain categories. In the single-domain category, the Age configuration yields the lowest performance with an Accuracy of 69.63\% and an F1-Score of 69.52\%, whereas Face achieves an Accuracy of 82.69\%. Feature integration in dual-domain schemes consistently enhances classification accuracy, led by Emotion $\oplus$ Face at 84.86\%. Peak GNB classification performance is attained by tri-domain Face $\oplus$ Emotion $\oplus$ Age with 85.05\% Accuracy and 85.05\% F1-Score. All GNB configurations uniformly select PCA 0.75 dimensionality reduction via GridSearchCV across all feature schemes.

The performance benchmark results of multinomial LR across all feature configurations are summarized in Table~\ref{tab:IX}. A key characteristic of the LR model is full feature retention, wherein all seven schemes select no PCA reduction (pca=None) \cite{ref49}. Empirical evaluation demonstrates that the tri-domain configuration Face $\oplus$ Emotion $\oplus$ Age achieves the highest performance with 92.73\% Accuracy and 92.73\% F1-Score using penalty parameter $C=0.1$ and the newton-cg solver. This tri-domain achievement surpasses the best dual-domain configuration Emotion $\oplus$ Face (92.41\% Accuracy, 92.40\% F1-Score) and single-domain Face (90.60\% Accuracy). These findings indicate the effectiveness of $L_2$ regularization in handling high-dimensional feature spaces without principal component compression \cite{ref50}.

The performance progression of SVM across all feature ablation stages is summarized in Table~\ref{tab:X}. Similar to the linear model, all SVM configurations consistently maintain the full representation space without PCA reduction (pca=None). Empirical evaluation reveals a tiered performance increase from single-domain Face (90.83\% Accuracy, 90.83\% F1-Score) to dual-domain Emotion $\oplus$ Face (93.29\% Accuracy, 93.29\% F1-Score), peaking in tri-domain Face $\oplus$ Emotion $\oplus$ Age with an Accuracy of 93.70\% and an F1-Score of 93.69\%. In terms of hyperparameters, the degree parameter value of 2 is active only for the poly kernel function, whereas RBF kernel-based models do not activate this parameter within the evaluated search space \cite{ref51}.

The results across the 28 experiments in Tables~\ref{tab:VII}--\ref{tab:X} demonstrate that SVM with tri-domain fusion Face $\oplus$ Emotion $\oplus$ Age delivers the highest performance, achieving 93.70\% Accuracy and 93.69\% F1-Score. Averaged across the seven feature configurations, the overall classifier performance hierarchy follows: SVM (91.47\%) > LR (90.40\%) > RF (82.81\%) > GNB (79.37\%). For the tri-domain SVM configuration, GridSearchCV selects a degree-2 polynomial kernel as the optimal configuration for demographic classification. This empirical finding applies specifically to the DemogPairs dataset and evaluated search space. This comparative evaluation remains descriptive without claiming statistical superiority, as this study does not conduct formal statistical hypothesis testing across classifiers.
