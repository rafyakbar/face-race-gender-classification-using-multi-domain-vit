Multinomial LR (Softmax regression) maps latent representations into six intersectional demographic classes via normalized posterior probabilities \cite{ref37}. For input vector $\mathbf{x} \in \mathbb{R}^D$ and class $c \in \{1, \dots, K\}$ with $K = 6$, the conditional probability is formulated in \eqref{eq:7}, where $\mathbf{w}_c$ and $b_c$ denote the weight vector and bias parameter of class $c$ \cite{ref38}:
\begin{equation}
P(y = c \mid \mathbf{x}) = \frac{e^{\mathbf{w}_c^T \mathbf{x} + b_c}}{\sum_{j=1}^K e^{\mathbf{w}_j^T \mathbf{x} + b_j}}
\label{eq:7}
\end{equation}

Model training minimizes categorical cross-entropy loss regularized with an $L_2$ penalty to prevent overfitting on high-dimensional representations \cite{ref39}. Hyperparameter tuning via 5-Fold Stratified Cross-Validation evaluates variations of feature scaling, PCA dimensionality reduction, five regularization values $C \in \{0.01, 0.1, 1, 10, 100\}$, three solvers (`lbfgs`, `saga`, `newton-cg`), and three maximum iteration limits (200, 500, 2000), producing 270 grid combinations with 1,350 total fits in Table~\ref{tab:V}.
